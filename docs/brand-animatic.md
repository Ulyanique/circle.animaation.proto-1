# Фирменное поле — речь, ужин, музыкальные сеты

**Второй готовый вид:** 1920×1080, 60 FPS, бесшовный цикл 24 с. Открыть `?scene=brand`; контрольный кадр — [brand-background.jpg](brand-background.jpg). Звук не встроен.

Золотой символ циркуля расположен по центру, название «Янтарный циркуль» — под ним. Даты и подзаголовка нет. Золотой свет, угловые кольца и пыль поддерживают фирменный язык интро, но без его стартовой вспышки и движения камеры.

Свет и графика распределены по кадру, а не собраны в одной диагонали: крупные кольца с разметкой стоят в левом верхнем и правом нижнем углах, в двух других — их уменьшенная и более тихая пара, а по кадру разбросаны линзовые кружки и низкое свечение снизу. Так ни один квадрант не остаётся пустым, а титр сохраняет спокойное поле вокруг.

На удержании за знаком расходятся и затухают тонкие копии его контура: они рождаются уже крупнее знака и не ложатся вторым контуром по силуэту. В интро этого фонового эффекта нет, а волны не заходят в область титра. После удержания текст, знак и построительная окружность уходят в обратном порядке, а короткий тёмный участок замыкает 24-секундный цикл. Если фон используется за выступающим, перед показом проверить читаемость названия из зала и не перекрывает ли человек центральную часть композиции.

Управление в предпросмотре: пауза, запись WebM одного цикла, возврат к стартовому интро. Кнопки не попадают в видеокадр. Для программного покадрового экспорта — `URL=http://localhost:5173/?scene=brand npm run render:frames`; для проверки кадра, состава титра, экспортного canvas и шва — `npm run verify:brand`.
