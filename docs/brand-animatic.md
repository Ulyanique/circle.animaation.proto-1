# Фирменное поле — речь, ужин, музыкальные сеты

**Второй готовый вид:** 1920×1080, 60 FPS, бесшовный цикл 24 с. Открыть `?scene=brand`; контрольный кадр — [brand-background.jpg](brand-background.jpg). Звук не встроен.

Золотой символ циркуля расположен по центру, название «Янтарный циркуль» — под ним. Даты и подзаголовка нет. Золотой свет, угловые кольца и пыль поддерживают фирменный язык интро, но без его стартовой вспышки и движения камеры.

Композиция выстроена крупно: знак занимает почти половину высоты кадра, а титр стоит в нижней трети — под ним больше нет пустого поля. Угловые кольца с разметкой только в левом верхнем и правом нижнем углах; в двух других углах дополнительных кругов нет.

На удержании за знаком видна тонкая построительная окружность с медленно вращающимися засечками и пылью на орбите. Она включается и настраивается независимо в разделе «Построительная окружность»; волн от логотипа здесь нет. После удержания текст, знак и построительная окружность уходят в обратном порядке, а короткий тёмный участок замыкает 24-секундный цикл. Если фон используется за выступающим, перед показом проверить читаемость названия из зала и не перекрывает ли человек центральную часть композиции.

Управление в предпросмотре: пауза, запись WebM одного цикла, возврат к стартовому интро. Кнопки не попадают в видеокадр. Для программного покадрового экспорта — `URL=http://localhost:5173/?scene=brand npm run render:frames`; для проверки кадра, состава титра, экспортного canvas и шва — `npm run verify:brand`.
