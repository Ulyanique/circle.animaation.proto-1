# Фирменное поле — речь, ужин, музыкальные сеты

**Вид №2:** 1920×1080, 60 FPS, цикл 24 с. Открыть `?scene=brand`; [контрольный кадр](brand-background.jpg). Звук не встроен. Циркуль — по центру, название — строго **под ним** в предпросмотре и в экспортном WebM.

## Ритм

| Время | Действие |
| --- | --- |
| 0–2,6 с | Из темноты медленно чертятся крайние кольца, риски и контур циркуля; свет и пыль оживают вслед за ними. |
| 2,6–5 с | Из контурного штриха выходит объёмный металл, по граням проходит тёплый блик. С 3,25 с по буквам гравируется название. |
| 5,05–6,15 с | Буквы последовательно заполняются золотом после обводки. |
| 6,15–21 с | Читаемая композиция: кольца, каустика, лучи, туман и пыль продолжают движение. Три оттиска настоящего SVG-контура циркуля расходятся за ним и затухают; сам металл слегка поворачивается в 3D, не зеркаля знак. |
| 21–23,5 с | Обратная сборке последовательность: заполнение титра уходит, остаётся его контур, затем исчезают контур, металл, свет и кольца. |
| 23,5–24 с | Короткая темнота закрывает шов, первый и последний кадры визуально совпадают. |

Фотопауза №8 повторяет тот же ритм с чуть более симметричным и тихим светом и рамкой видоискателя; ось и масштаб циркуля совпадают с №2. Финал №9 длится 18 с, добавляет строку «История продолжается» и закрывает её раньше названия и символа. Волны там меньше, чтобы не заходить на титр. №1 сохраняет собственный исходный тайминг.

Изменение длительности в пульте растягивает **удержание**, а не скорость гравировки и выхода. Автоматическая цепочка по умолчанию выключена; для речи на фоне можно поставить сцену на паузу во время удержания. При экспорте браузер кодирует кадры по абсолютному времени, поэтому результат не зависит от скорости предпросмотра.

`npm run verify:brand` и `SCENE=photo-pause|finale npm run verify:priority` проверяют проявление, титр, фон и пиксельный шов. `npm run verify:motion` сравнивает реальные пиксели двух областей фона на 9-й и 10-й секундах всех трёх видов и повтор того же кадра после перемотки. Пульт не попадает в экспорт.
