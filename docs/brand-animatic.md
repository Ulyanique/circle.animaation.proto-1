# Фирменное поле — речь, ужин, музыкальные сеты

**Второй готовый вид:** 1920×1080, 60 FPS, бесшовный цикл 24 с. Открыть `?scene=brand`; контрольный кадр — [brand-background.jpg](brand-background.jpg). Звук не встроен.

Крупный золотой символ циркуля находится слева от единственной надписи «Янтарный циркуль». Дата, подзаголовок, разметка, кольца и искры убраны: фокус остаётся на человеке или программе вечера, а не на очередном появлении титра. Край освещения едва поддерживает металл; фон тёмный, без периодических вспышек.

Движение — только очень слабое дыхание символа на протяжении цикла. По обе стороны стыка композиция неподвижна; нет затемнения или новой сборки каждые 24 секунды. Если фон используется за выступающим, перед показом проверить читаемость названия из зала и не перекрывает ли человек центральную часть композиции.

Управление в предпросмотре справа внизу: пауза, запись WebM одного цикла, возврат к заставке ожидания. Кнопки не попадают в видеокадр. Для программного покадрового экспорта — `URL=http://localhost:5173/?scene=brand npm run render:frames`; для проверки кадра, состава титра, экспортного canvas и шва — `npm run verify:brand`.
