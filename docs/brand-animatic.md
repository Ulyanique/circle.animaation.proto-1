# Фирменное поле, фотопауза и финал — аниматик фазы 2

**Формат:** 1920×1080, 60 FPS. №2 и №8 — бесшовные циклы по 24 с, №9 — 18 с. Ручная цепочка и опциональная автоматическая последовательность №1→№2→№8→№9→№1 сохраняются; интро-акценты `OpeningPulse` в эти три вида не протекают. Все новые огибающие — чистые функции абсолютного `t` и конфига, поэтому перемотка и покадровый экспорт дают тот же кадр. [Контрольный кадр №2](brand-background.jpg).

## №2 · Фирменный фон

Циркуль опущен ниже центра (`layout.logoY = 0.55`), название — строго под ним. На фоне появился отдельный [`DecorLayer`](../src/decor-layer.js): по умолчанию `blueprint-arcs` — три тонкие чертёжные дуги, мягкие солнечные блики и редкая золотая пыль. Пресеты `blueprint-arcs`, `sun-rays`, `gold-dust`, `none`, а также прозрачность, целое число оборотов за цикл, масштаб, плотность и цвет настраиваются в `Настройки → Декор фона`. Декор гаснет вместе с огибающей крайних колец, поэтому первый и последний кадры цикла по-прежнему совпадают.

| Время | Действие |
| --- | --- |
| 0–2,6 с | Из темноты медленно чертятся крайние кольца, риски и контур циркуля; декор входит вместе со светом и пылью. |
| 2,6–5 с | Из контурного штриха выходит объёмный металл, по граням проходит тёплый блик. С 3,25 с по буквам гравируется название. |
| 5,05–6,15 с | Буквы последовательно заполняются золотом после обводки. |
| 6,15–21 с | Читаемая композиция: кольца, каустика, лучи, туман, пыль и выбранный декор продолжают движение. Три оттиска SVG-контура расходятся за знаком и затухают. |
| 21–23,5 с | Обратная сборке последовательность; декор уходит вместе с крайним светом. |
| 23,5–24 с | Короткая темнота закрывает шов. |

## №8 · Фотопауза

Логотип теперь строго в центре (`layout.logoY = 0`). Маленькая рамка видоискателя вокруг знака скрыта по умолчанию (`viewfinderOpacity = 0`) и остаётся доступной как старая настройка. Вместо неё [`PhotoPauseDecor`](../src/photo-pause-decor.js) ставит **уголки-скобки по краям экрана** и выводит повторяющуюся по окружности строку `фотопауза • фотопауза • …`. Число повторов, радиус, размер шрифта, цвет, прозрачность, направление и целое число оборотов за цикл, отступ/длина/толщина/прозрачность уголков настраиваются в `Настройки → Фотопауза №8`; включение уголков — `Композиция → Уголки по краям`. Один оборот за 24 с возвращает круговую строку в исходное положение точно к шву, а на самом шве весь декор обнуляется.

Титр «Фотопауза» остаётся под центральным знаком и проходит тот же ритм контур → заливка → обратный уход; вход и выход повторяют кинематографический ритм №1. Первый и последний кадры совпадают. [Контрольный кадр](photo-pause.jpg) снят до фазы 2 и показывает прежнюю композицию; визуальную приёмку делает пользователь по новому скриншоту.

## №9 · Финал

[`FinaleSequence`](../src/finale-sequence.js) заменяет прежний простой «обратный уход» отдельной раскадровкой поверх общего рендера. Точки ниже — смещения от начала финального ухода (`exit = 15,0 с` при 18-секундном цикле); все они настраиваются в `Настройки → Финал №9`.

| Смещение | Стадия |
| --- | --- |
| +0,05…+0,85 с | Надписи стираются справа налево: заливка возвращается в контур, `CaptionRenderer` ведёт обратную клип-маску. |
| +0,35…+1,05 с | Логотип плавно переходит с рабочей оси в центр кадра. |
| +0,80…+1,55 с | Знак удаляется от зрителя по `z`, уменьшается в масштабе, золото гаснет. |
| +1,15…+1,75 с | Контур отматывается к первой точке чертежа в обратном порядке. |
| +1,45…+2,45 с | В центре остаётся та же тонкая построительная окружность, которой открывается №1 (`center-construction`). Затем она гаснет до шва. |
| +2,45…+3,00 с | Темнота закрывает цикл и цепочку; финальный круг на последнем кадре отсутствует. |

`finalCircle` по-прежнему можно переключить на `last-arc` или `corner-rings`; выбранный пользователем вариант `center-construction` остаётся значением по умолчанию. Отдельные множители `circleOpacity`, `circleRadius`, `depthTravel` и все старты стадий лежат в JSON сцены. [Контрольный кадр](finale.jpg) снят до фазы 2.

## Границы и приёмка

- Один экран 1920×1080 / 60 FPS, максимальное качество, без пониженного пресета.
- `renderAt(t)`, seek и покадровый WebM детерминированы; швы и цепочка №1→№2→№8→№9→№1 сохраняются.
- Оверлеи редактора и панели не попадают в экспорт; WebM кодируется в браузере пользователя, полный 15,3-с ролик в software-среде не кодировался.
- `tests/phase2.test.js` проверяет детерминизм декора, целое число оборотов №8, порядок стадий №9 и обратное стирание титра. Быстрые `npm test`, typecheck, build и `git diff --check` пройдены.
- По договорённости с пользователем длинные headless-снимки и покадровые A/B не запускались; кадры `docs/storyboard/` остаются опорными для №1, новые контрольные JPEG для №2/№8/№9 в этом проходе не переснимались. Пользователь смотрит результат в браузере и присылает скриншоты.
- PR #2 остаётся открытым; без отдельной команды не сливаем.
