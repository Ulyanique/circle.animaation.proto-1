# Архитектура заставок — инкрементальный этап

Сохраняем Three.js/WebGL + Vite и готовую первую заставку. Переход на новый рендерер или React не нужен для покадрового видео: важнее неизменные кадры, последовательность и возможность вернуться к любому `t` без прогрева.

- `src/scenes/catalog.js` — один формат 1920×1080, 60 FPS и **план** девяти видов. Только `waiting` имеет статус `ready` и настройки; остальные не выданы за работающие сцены.
- `src/scenes/waiting.js` — параметры первой заставки, извлечённые из `src/config.js` без изменения значений. `config.js` остаётся совместимым с UI, JSON и прежними сохранёнными настройками браузера.
- `src/runtime.js` — без DOM и WebGL: длительность цикла, `advance(elapsed)` с учётом паузы и скорости, независимый `renderAt(t)` через `update(t,dt)/render(dt)` адаптера.
- `src/scene.js` — текущий адаптер Three.js; внутри него остаются логотип, свет и эффекты первой заставки. `src/main.js` подключает сцену к движку, панели и записи.
- Единый `drawCompositeFrame` в `main.js` используется и браузерной записью WebM, и проверкой `compositeFrameAt(t)`. Последняя возвращает canvas реального размера, чтобы проверить наличие титра в экспорте.

**Инварианты:** 1920×1080 без второго пресета; абсолютное время, детерминированный seek и пиксельный шов; неизменная длительность 15,3 с и исходные художественные настройки. Загрузчик/панели — только интерфейс просмотра, не часть экспортируемого кадра. LYGIA остаётся в проекте с сохранённой лицензией при подтверждённом некоммерческом использовании.

## При добавлении следующей сцены

1. Согласовать содержание и тайминг; запись `planned` в каталоге сама по себе не создаёт ролик.
2. Добавить описание параметров и отдельный адаптер с `update(t,dt)`/`render(dt)` либо повторно использовать существующий, не меняя поведение `waiting`.
3. Подключить выбор сцены и независимое хранение пользовательских настроек **только после** появления второго работающего адаптера.
4. Записать референсные кадры и пройти `npm test`, `npm run typecheck`, `npm run build`, `npm run verify:loader`, `npm run verify:render`; проверить экспорт в браузере на целевом экране.

Типизация сейчас намеренно охватывает только чистый runtime и описание сцен (`tsconfig.json`). Перевод шейдеров/рендерера на TypeScript — отдельное решение после двух-трёх реальных заставок, если появится измеримая проблема сопровождения.
