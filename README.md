# circle.animaation.proto-1

Зацикленная 3D-анимация золотого логотипа (three.js + postprocessing).

## Запуск

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # сборка в dist/

При первом открытии отображается тёмный экран подготовки сцены. Он исчезает **после первого WebGL-кадра и загрузки шрифтов**, не попадая в видеозапись. Если модули не загрузились или WebGL недоступен, вместо белой страницы появится сообщение об ошибке с кнопкой «Повторить загрузку». Проверка сценария отказа: `npm run verify:loader` (контрольный кадр: [`docs/loader-preview.jpg`](docs/loader-preview.jpg)).

**Если файлы приложения не загружаются:** не открывайте исходный `index.html` напрямую из файлового менеджера — используйте `npm ci` и `npm run dev`. Для размещения на сайте выполните `npm run build` и публикуйте содержимое `dist/`, а не исходники. Готовая сборка работает и в корне сайта, и в подпапке; адрес подпапки должен оканчиваться `/`. Сообщение об ошибке показывает путь недоступного обязательного файла без параметров URL. Отказ загрузки сторонней аналитики и других необязательных ресурсов не скрывает заставку.

## 01 · Стартовое интро

Первый ролик — открытие вечера, а не экран ожидания. Его можно открыть по `?scene=intro` (старый адрес `?scene=waiting` тоже работает). Вступление начинается с разметки и двух построительных точек; камера подъезжает к обращённому прямо символу, свет раскрывается лучами и коротким бликом; знак не вращается в 3D. Когда появляются надписи, лучи становятся мягче, но остаются в кадре. На готовой композиции нет фоновых копий контура или пунктирного кольца вокруг логотипа: расходящиеся контурные волны сохранены только для фотопаузы №08. Угловые огни и в интро, и в фоновом ролике остаются только в двух местах — слева сверху и справа снизу.

Крупное центральное перекрестие и угловые перекрестия размечают композицию → две противоположные световые точки замыкают окружность → одна передаёт движение контуру циркуля → проявление из тени → удержание → последовательный уход даты, подзаголовка и названия → опускание знака → уход боковых кругов → обратная обводка знака → две точки сворачивают окружность, исчезает разметка → тёмный шов. Продолжительность всего обратного выхода задаётся фазой «Уход»; при короткой фазе все этапы проходят быстрее. Буквы последовательно гравируются контуром и заполняются золотом; под знаком остаются название, подзаголовок и дата. На удержании фон, пыль и крайние кольца продолжают двигаться.

Цикл интро по умолчанию длится **19,1 с**. Сначала точка рисует круг в центре, затем проявляется логотип, рисуются два боковых круга, знак поднимается и появляются надписи. Полностью собранная композиция остаётся читаемой около **5 с** до начала ухода. Длительности фаз меняются в панели настроек. Другие готовые сцены сохраняют общий золотой язык, последовательность титров и обратный уход, но без стартового светового акцента интро. Время анимации не замедляется при падении частоты кадров.

## Настройки
⚙ в правом верхнем углу (или клавиша S) доступна в каждой сцене. Пробел — пауза,
двойной клик по ползунку — сброс одного поля.

- **Вкладки 01 / 02 / 08 / 09** переключают сцену вместе с её собственным набором
  параметров: правка фонового ролика не меняет интро и наоборот.
- **Экспорт сцены** и **Экспорт проекта** выдают JSON одной сцены или всех четырёх
  сразу; «Копировать» кладёт его в буфер, «Скачать .json» сохраняет файл.
- **Импорт** принимает и JSON сцены (частичный: недостающие ключи берутся из
  умолчаний), и файл проекта с объектом `scenes`.
- **Сброс сцены** возвращает умолчания только этой сцены.
- Настройки хранятся в браузере отдельно для каждой сцены
  (`circle-anim-settings-v2:<сцена>`); старый общий ключ читается один раз как
  настройки интро.

Чтобы присланный JSON стал новым умолчанием, перенесите его значения в
`WAITING_DEFAULTS` (`src/scenes/waiting.js`) для интро или в
`createSharedSceneConfig` (`src/scenes/shared-visuals.js`) для фоновых сцен, а затем
нажмите «Сброс сцены» — сохранённые в браузере значения перекроют код до сброса.

Титры экспериментально обрисовываются тремя линиями вдоль контура каждого глифа,
затем заполняются; тот же контур используется в кадре записи. Если контур шрифта
недоступен, остаётся прежнее раскрытие маской.

### 08 · Фотопауза
Логотип по умолчанию расположен в центре; вокруг него движется круговая надпись,
а у краёв кадра находятся четыре тонких уголка видоискателя. Сначала плавно раскрывается отключаемая апертура объектива, затем появляется контур знака. Логотип сперва неподвижно прорисовывается контуром, затем плавно начинает вращаться вокруг вертикальной оси, проходя через вид ребром и лицом; скорость задаётся числом оборотов за 20 секунд (0 выключает вращение). Надпись и уголки
рисуются внутри сцены, поэтому входят и в запись. В разделе «Круговая надпись и рамка» можно
изменить текст, количество повторов, размер, радиус, скорость вращения, цвет,
прозрачность, параметры апертуры, радиус пунктирного круга, размеры и мягкую пульсацию уголков. Шрифт выбирается в разделе «Типографика».
При первом запуске прежнее стандартное положение логотипа 0,86 автоматически
переносится в центр (0); остальные сохранённые параметры не сбрасываются.
Другие значения положения сохраняются, а после переноса высоту можно настроить заново. Прежний стандартный масштаб 0,47 один раз заменяется на 0,58; остальные сохранённые размеры не меняются.
При крайних значениях размера логотипа и радиуса надписи возможно пересечение.

### 09 · Финал
Вход выполнен в стиле интро: разметка, окружность с двумя точками, знак,
боковые круги и подъём перед надписями. На выходе название исчезает, знак
возвращается к центру, удаляется и стирается вместе с окружностью. Надпись
«История продолжается» перемещается в центр, остаётся на тёмном фоне и плавно
стирается последней. Надпись, её цвет, размер и смещение можно изменить.
В «Финальном уходе» регулируются глубина и конечный масштаб, а общая длительность
последовательности задаётся фазой «Уход» в таймлайне. В настройках «Финальный уход» отдельно задаются длительности прорисовки фразы, её перемещения к центру, удержания и стирания. Если этапы не помещаются в отведённое время, они автоматически сокращаются; увеличьте удержание или фазу «Уход» на таймлайне.

### Основные группы параметров
- `intro.cornerDuration`, `intro.liftDuration`, `intro.titleDelay` — длительность появления двух боковых кругов, подъёма знака и пауза до титров (только сцена 01). Если сделать эти интервалы слишком длинными или удержание слишком коротким, титры могут не успеть появиться до ухода.
- `typography.font` — шрифт титров для текущей сцены: Cormorant Garamond, Playfair Display, Prata, PT Serif, Manrope или Unbounded. Выбор сохраняется в JSON; шрифты входят в сборку.
- `logo.depth`, `logo.bevel`, `logo.outlineWidthPx` — толщина логотипа, скос и контур (логотип растёт во время проявления).
- `lights.topGlow` — свечение над логотипом (центр кадра).
- `topIllumination.raysEnabled`, `raysIntensity`, `raysSpeed`, `raysColor` — независимое включение, яркость, скорость и цвет верхних лучей в каждой сцене. Лучи следуют центру логотипа; их настройки не выключают ореол и освещение металла.
- `background.lowerShade` — затемнение нижнего левого угла; `background.godRays`, `background.brushed`, `background.fog` — лучи, диагональная текстура и туман.
- `timeline.ringsIntro` — длительность прорисовки крайних колец; `rings.speed` — скорость движения рисок; `rings.constructionOpacity` — пунктирная разметка «циркулем».
- `particles.rayLift` — подсветка пыли кольцами.
- `post.dofEnabled` — размытие (выключено, кадр чёткий); `post.chromaticAberration` — радиальная аберрация у краёв; `post.bloomIntensity` — блум.

Блики боке используют фрагмент [LYGIA `generative/random.glsl`](src/shaders/lygia-random.glsl); его [условия лицензии и уведомления](src/shaders/LYGIA-LICENSE.md) сохранены в репозитории. Применять этот код здесь разрешено с учётом подтверждённого некоммерческого статуса проекта; при изменении назначения нужно заново проверить лицензию.

## Основа для серии

Смена фреймворка не требуется: `src/runtime.js` отвечает за абсолютное время, паузу и точный `renderAt(t)` через интерфейс `update/render`, не импортируя Three.js. `src/scenes/catalog.js` задаёт единый формат **1920×1080 / 60 FPS** и план девяти видов. **Реализованы виды №1, 2, 8 и 9:** интро (`src/scene.js`), фирменный фон (`src/brand-scene.js`), фотопауза (`src/photo-pause-scene.js`) и финал (`src/finale-scene.js`). Виды №3–7 остаются планами, а не фиктивными роликами.

`npm run typecheck` постепенно проверяет типы движка и описаний сцен без перевода шейдеров на другой язык. `npm run verify:render`, `npm run verify:brand`, `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` проверяют покадровый шов, расположение текста и фазы анимации. `npm run verify:intro` проверяет свет и отсутствие фоновых контуров в интро; `npm run verify:motion` сравнивает реальные пиксели движущегося фона; с `SCENE=photo-pause` проверяет также волны фотопаузы.

## Пульт показа и монтажная шкала

Курсор над заставкой больше не скрывается. Пульт внизу появляется при движении мыши и уходит после 3,2 с бездействия; кнопка ⚙ остаётся видимой во всех готовых сценах, приглушаясь в простое; при работе с настройками или клавиатурной фокусировке не прячутся. **R** закрепляет/открепляет пульт.

- Кнопки **01 / 02 / 08 / 09** переключают готовые виды без перезагрузки страницы: стоп-кадр с титрами прежнего вида плавно растворяется в новом за 0,9 с.
- По умолчанию переход **ручной**. «Авто: вкл.» включает цепочку **01 → 02 → 08 → 09 → 01** после каждого цикла; для длительной речи оставьте авто выключенным. При записи переключение заблокировано.
- Ползунок прокручивает **текущий** цикл, рядом таймкод и шаг **−1 / +1 кадр** (стрелки клавиатуры). Перемотка ставит сцену на паузу. Поле «Цикл» изменяет длительность, корректируя фазу удержания, не качество рендера. Для видов 02, 08 и 09 минимум 12,5 с, чтобы титры успели собраться и остаться читаемыми.
- Пульт не входит в кадр, не добавляет звук и не меняет формат видео. **«● Цикл»** сохраняет один цикл текущего вида; **«● Вся цепочка»** записывает одним MP4 01 → 02 → 08 → 09 с теми же плавными переходами. Запись цепочки всегда начинается с 01, даже если сейчас открыт другой вид, и заканчивается на 09; повторяющееся автоматическое воспроизведение в файл не входит. На время записи переключение и перемотка блокируются. Пауза — кнопка ▶/Ⅱ или пробел; панель настроек ⚙ доступна во всех четырёх сценах.

Проверка управления и переходов: `npm run verify:operator`; единого MP4 (ускоренный прогон без изменения художественных defaults): `npm run verify:chain` (нужны запущенный сервер и Chromium).

## Фирменный фон

Откройте `?scene=brand`. По умолчанию знак и построительная окружность находятся в центре; вокруг вращается надпись «Янтарный циркуль». Надпись настраивается отдельно в свойствах элемента и разделе «Круговая надпись и рамка», а прежний отдельный титр по умолчанию скрыт и может быть включён снова. Волн от логотипа в этой сцене нет. Сохранённое прежнее стандартное положение знака переносится в центр один раз; пользовательские положения и изменённый титр сохраняются. Цикл — 24 с; композиция и текст входят в видео.

## Фотопауза и финал

- `?scene=photo-pause` (№8): 24 с, тот же фирменный фон и анимация, с круговой надписью «Фотопауза», пунктиром рядом с ней и мягко движущимися к центру уголками видоискателя.
- `?scene=finale` (№9): 18 с; после прорисовки символа под ним посимвольно собираются «Янтарный циркуль» и «История продолжается». Затем текст и символ уходят в обратном порядке. [Контрольный кадр](docs/finale.jpg).

Без дополнительных надписей и звука. У каждого вида собственный таймлайн, но тот же экспортный canvas 1920×1080 и запись MP4 через кнопку «Записать цикл». При необходимости проверить оба вида: `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` (сервер должен работать). Нажатие номера в панели переключает предпросмотр.

## Видео и проверка рендера
Первая заставка — логотип, «Янтарный циркуль», «Вечер ретроспектива», 20 ноября 2026 года.
Кадр всегда выводится в **1920×1080** с MSAA, SMAA и постобработкой; режим пониженного качества не предусмотрен.
Подпись и логотип рассчитываются по абсолютному времени кадра, а частицы создаются с фиксированным зерном случайности: перемотка и покадровый рендер воспроизводимы без «прогрева» анимации.

1. `npm ci` и `npm run dev` (оставить сервер запущенным).
2. Указать `CHROME=/путь/к/chrome` (Chromium/Chrome) или выполнить `scripts/setup-headless.sh` для портативного Chromium.
3. `npm test` — быстрые тесты без браузера; `npm run verify:render` — проверка браузерного рендера (ошибки, перемотка, шов и разрешение). `npm run verify:motion` проверяет настоящие пиксели волн, фона и обратной орбиты, а также отсутствие волн в области титров; при `OUT=out/motion` сохраняет контрольные кадры входа, удержания и обратного ухода. `npm run verify:caption` сравнивает титры предпросмотра с экспортным canvas на контрольных кадрах, включая частичное проявление букв (нужен запущенный dev-сервер). `npm run verify:caption:export` дополнительно проверяет композит с настоящим WebGL в видах 01 и 09; на программном рендерере эти тесты могут выполняться несколько минут.
4. `FPS=60 OUT=out/frames npm run render:frames` — PNG-кадры одного цикла. Длительность и задержка считываются из текущих настроек браузера. Кадры нумеруются `f00000.png` и далее; последний кадр находится **перед** концом цикла.
5. `FPS=60 IN=out/frames OUT=out/logo-loop.mp4 npm run render:encode` — MP4 через установленный `ffmpeg`. Для монтажа без потерь используйте непосредственно PNG-последовательность.

Арт-дирекшен интро, покадровый план и контрольные style frame: [`docs/animatic.md`](docs/animatic.md). Отбор GitHub-инструментов и эффектов с лицензиями и критериями внедрения: [`docs/github-motion-research.md`](docs/github-motion-research.md). Семь обзорных кадров можно переснять командой `OUT=docs/storyboard npm run render:storyboard` (они не заменяют финальный PNG-рендер).

`URL=http://localhost:5173/` можно переопределить для команд с браузером. Экспорт одного цикла и всей цепочки создаёт MP4 покадрово: каждый кадр рассчитывается с фиксированным временем и проверяется в готовом файле. Скорость компьютера влияет только на время экспорта, а не на пропуск кадров. Для экспорта нужны WebCodecs и поддержка H.264 (актуальный Chrome/Edge, HTTPS или localhost); при отсутствии поддержки файл не создаётся. Экспорт можно отменить. Готовое видео временно хранится в памяти браузера, поэтому длинные ролики требуют достаточно памяти.
Все готовые виды завершаются обратной прорисовкой и коротким тёмным участком на шве. При паузе короче 0,45 с возврат по окружности пропускается, чтобы оставить тёмный шов. Во время удержания фон продолжает двигаться; только в фотопаузе волны от силуэта повторяются с затуханием. Проверки сравнивают реальные пиксели первого и последнего кадра при 60 FPS; для стандартных настроек они совпадают. При изменении длительностей фаз проверьте шов заново.

## Редактирование на кадре

Кнопка «Редактировать» в левом верхнем углу ставит ролик на паузу и показывает
собранную композицию. Перетащите рамку логотипа, названия, подзаголовка или даты; потяните за
квадратик на рамке, чтобы изменить размер. Клавиши + и − также меняют размер.
При входе выбран логотип; выберите другой элемент на кадре или в списке слева.
Рамка и маркер размера активного элемента подсвечены, остальные приглушены.
Кнопка с глазом справа от элемента скрывает или показывает его; скрытый элемент
можно снова включить в списке. Видимость сохраняется по сценам, входит в JSON и
видео и поддерживает отмену/повтор. Для круговой надписи и окружности это те же
переключатели, что в настройках; скрытие логотипа также прячет волны от его контура,
но не отключает другие эффекты сцены. Свойства выбранного элемента находятся в правой
панели: там можно выровнять элемент или сбросить позицию и размер по отдельности.
На ширине окна от 781 пикселя панели расположены по сторонам кадра; на узком экране панели открываются кнопками «Слои» и «Свойства» поверх кадра. Список пока
показывает элементы готового шаблона и добавленные слои. Кнопка
«Добавить текст» создаёт до восьми дополнительных надписей на сцену; у каждой
можно изменить текст, цвет, положение и размер, скрыть её или удалить через
свойства. Кнопки «Выше» и «Ниже» меняют порядок только между своими надписями: в списке и таймлайне передние показаны выше, а новые и дублированные появляются поверх остальных. Порядок сохраняется в JSON и совпадает в редакторе и видео; старые настройки сохраняют прежний порядок слотов. Добавление, удаление и перестановка поддерживают отмену/повтор. Дополнительные
надписи используют шрифт сцены. По умолчанию они появляются и уходят вместе
с названием; в свойствах можно выбрать «Своё время» и задать начало, конец и
плавность отдельно для каждой надписи. Начало и конец — проценты цикла после
стартовой задержки (показаны также секунды таймлайна); при изменении длительности
сцены они масштабируются вместе с ней; скорость воспроизведения влияет на реальное
время. Перемотайте нижним пультом внутрь интервала, чтобы увидеть надпись на
паузе. Плавность задаётся в процентах от самого интервала для каждого из переходов. Изменения поддерживают отмену/повтор, входят
в JSON и видео. Для каждой построительной окружности, каждого облака частиц и каждого
фонового свечения также можно выбрать в свойствах «Своё время» и задать
индивидуальный интервал и плавность. До и после интервала эффект не виден;
перемотайте воспроизведение внутрь интервала, чтобы расположить его на кадре.
По умолчанию эффекты сохраняют прежние фазы появления и ухода.
Под кадром находится таймлайн добавленных текстов и эффектов. Над дорожками показаны базовые фазы сцены: метки меняют длительность прорисовки/проявления и ухода/паузы пропорционально, за счёт удержания, не изменяя общий цикл. Мышь и стрелки позволяют перемещать метки; Shift ускоряет шаг, Escape отменяет жест, изменения можно отменить. При увеличении длительности в пульте меняется только удержание. Дополнительные такты интро (появление боковых кругов, подъём и титры) пока частично проходят внутри удержания и настраиваются отдельно; собственные интервалы элементов по-прежнему заданы в процентах от всего цикла. Строка «По сценарию»
не показывает точный интервал: нажмите её, чтобы включить «Своё время». После этого
границы цветного отрезка можно перетаскивать мышью или менять стрелками клавиатуры;
Shift ускоряет шаг, Escape отменяет текущий жест. Один жест — один шаг истории.
Нажатие или перетаскивание по верхней линейке перематывает и ставит воспроизведение
на паузу; линейка показывает секунды цикла после стартовой задержки. Штатные знак,
титры и боковые эффекты пока не представлены отдельными дорожками. Таймлайн не
попадает в видео. Ключевые кадры, загрузка изображений и произвольный порядок
всех элементов, включая WebGL-эффекты и штатные титры, ещё не реализованы.
В свойствах надписи можно сразу изменить её текст и цвет, а также вернуть исходные
текст или оформление. Цвет круговой надписи фотопаузы теперь независим от
уголков; прежние JSON без отдельного цвета сохраняют общий цвет. В свойствах знака
меняется общий цвет золота сцены (он влияет и на связанные эффекты), у
окружности — цвет декора. Тексты и цвета сохраняются по сценам в настройках и
JSON и используются в видео. Для каждой строки обычных титров доступно до 120
символов, для круговой надписи — до 40. При
перетаскивании края и центры притягиваются к кадру и другим элементам;
пунктирные направляющие показывают совпадения. Зажмите Alt для свободного
перемещения без прилипания. Стрелки перемещают выбранный элемент, Shift ускоряет шаг.
Кнопки «Отменить» и «Повторить» (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z или Ctrl+Y)
возвращают перемещение, размер, выравнивание, видимость, текст, цвет и сброс на кадре. Один жест —
один шаг; до 100 шагов хранятся отдельно для каждой сцены до перезагрузки.
Правки других настроек панели не входят в историю; при изменении в панели
параметра, который уже есть в истории, или при импорте/сбросе сцены история
этой сцены очищается, чтобы не затереть новое значение. Escape во время
перетаскивания отменяет текущий жест.
В свойствах добавленных надписей, построительных окружностей, облаков и свечений
есть кнопка «Дублировать». Копия занимает свободный слот того же типа, наследует
настройки, видимость и время, и слегка сдвигается, чтобы её было удобнее выбрать.
Дальнейшие изменения копии не затрагивают оригинал; дублирование отменяется одним
шагом. Если все слоты этого типа заняты, кнопка недоступна. Встроенные логотип,
титры и фоновые круги пока не дублируются.
В интро и финале на раннем этапе включено крупное центральное перекрестие с угловыми перекрестиями; окружность сохраняется. В остальных сценах через список элементов доступны чертёжные направляющие; в сцене 02 они по умолчанию выключены. Их можно отключить глазом, переместить, изменить размер, цвет и время; перекрестия привязаны к центрам двух существующих боковых кругов и не смещаются вместе с центральной разметкой.
«Готово» закрывает редактор; воспроизведение можно продолжить из пульта.
Изменения сохраняются отдельно для каждой сцены и входят в JSON и экспорт.
В фирменном фоне и фотопаузе круговую надпись можно сдвинуть за круглую ручку на её верхнем
крае; соседний квадратик меняет радиус. Размер букв круговой надписи задаётся
отдельно в настройках, а её положение отсчитывается от логотипа.
В любую сцену можно добавить до четырёх построительных окружностей кнопкой под
списком элементов. Каждую можно переместить за круглую ручку, масштабировать,
настроить, скрыть или удалить. Привязка к логотипу включается отдельно для
каждой окружности и переключается без скачка положения. В сцене 02 первая
окружность уже добавлена и привязана к знаку; другие сцены по умолчанию не
изменяются. Удаление освобождает слот для новой окружности.
Кнопка «Добавить облако частиц» создаёт до четырёх независимых облаков на сцену.
Каждое можно перемещать, масштабировать, скрывать и удалять отдельно от знака,
фоновых кругов и других облаков. Цвет задаётся в свойствах, количество, размер
частиц, яркость и скорость вращения — в «Настройках элемента». У каждого нового облака
свой воспроизводимый рисунок частиц; при дублировании рисунок копируется. Удалённое
облако освобождает слот для нового.
По умолчанию облака появляются и уходят вместе с фазами сцены, а существующие
фоновые частицы настраиваются отдельно.
Кнопка «Добавить свечение» создаёт до четырёх фоновых ореолов на сцену. Каждый
выбирается отдельно в списке: его положение, радиус, цвет и видимость независимы
от других ореолов, логотипа и боковых кругов; яркость и пульсация задаются в
настройках выбранного элемента. При удалении освободившийся слот можно занять
новым свечением. По умолчанию ореолы появляются и уходят по фазам сцены. Это визуальное
свечение на фоне, а не источник освещения металла.
Штатный «Верхний свет и ореол» доступен во всех сценах в списке элементов:
круглая ручка рядом с центром ореола перемещает его вместе с источником света,
который освещает металл. Размер и цвет ореола, цвет источника и видимость можно
менять отдельно от логотипа; яркость обоих задаётся в настройках «Свет и тени».
Ореол масштабируется, но радиус действия источника света не меняется. Перемещение,
размер, цвет и видимость поддерживают отмену/повтор и сохраняются в JSON. По
умолчанию сохраняются исходные положение, цвета и фазы сцены; отдельных копий и
собственного тайминга у штатного света пока нет.
Левый и правый фоновые
круги теперь выбираются в списке или за круглые ручки в их центрах; у каждого
отдельно можно переместить центр, изменить масштаб и цвет свечения или скрыть
его вместе с привязанными орбитальными частицами, боке и светом на фоне.
Основной цвет линий и прочие параметры пока общие и доступны через «Настройки
элемента». Если общий эффект колец выключен в настройках, кнопка видимости
включает его обратно (и восстанавливает ранее включённые стороны). Декоративные
линии, общий фон и некоторые существующие эффекты пока не являются отдельными перемещаемыми
слоями; произвольное добавление других типов объектов ещё не реализовано. Рамки редактора не попадают в видео. Быстрая проверка интерфейса без WebGL:
`URL=http://localhost:5173 npm run verify:editor:lite`.
