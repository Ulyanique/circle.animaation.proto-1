# circle.animaation.proto-1

Зацикленная 3D-анимация золотого логотипа (three.js + postprocessing).

## Запуск

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # сборка в dist/

При первом открытии отображается тёмный экран подготовки сцены. Он исчезает **после первого WebGL-кадра и загрузки шрифтов**, не попадая в видеозапись. Если модули не загрузились или WebGL недоступен, вместо белой страницы появится сообщение об ошибке с кнопкой «Повторить загрузку». Ошибки сторонних скриптов, которые может добавлять прокси предпросмотра (например, Cloudflare Insights), не считаются ошибкой загрузки приложения. Проверка обоих случаев: `npm run verify:loader` (контрольный кадр: [`docs/loader-preview.jpg`](docs/loader-preview.jpg)).

## Цикл
Световая точка намечает окружность тонкой лентой с коротким сужающимся световым хвостом → передаёт движение контуру циркуля → проявление из тени (радиальный шумовой фронт) → удержание с пульсацией и
плавным увеличением → последовательный уход даты, подзаголовка и названия → уход золота →
детали контура уходят, последняя дуга отматывается к первой точке → тёмная пауза → повтор.
По умолчанию цикл длится **15,3 с**, а полностью собранная композиция остаётся читаемой около **5,1 с** до начала ухода. Длительности фаз меняются в панели настроек. Буквы в каждой строке сначала по очереди гравируются тонким контуром, затем по очереди заполняются золотом; надписи слегка поднимаются на место. Крайние кольца медленно строятся дугами вместе с рисками, рядом на короткое время возникают солнечные блики и мягкое боке. Те же движения повторяются в браузерной записи. Время анимации не замедляется при падении частоты кадров.

## Настройки
⚙ в правом верхнем углу (или клавиша S). Пробел — пауза. Двойной клик по ползунку — сброс.
- **Экспорт JSON** — копировать/скачать текущие настройки.
- **Импорт** — вставить JSON и «Применить».
- **Сброс** — значения первой сцены из `src/scenes/waiting.js` (`WAITING_DEFAULTS`).

Чтобы присланный JSON стал значением по умолчанию, перенесите его в `WAITING_DEFAULTS` в `src/scenes/waiting.js` (`src/config.js` по-прежнему экспортирует совместимый `DEFAULTS`).
После обновления визуальных значений по умолчанию нажмите **Сброс** в панели: ранее сохранённые в браузере настройки продолжают действовать до сброса.

### Основные группы параметров
- `logo.depth`, `logo.bevel`, `logo.outlineWidthPx` — толщина логотипа, скос и контур (логотип растёт во время проявления).
- `lights.topGlow` — свечение над логотипом (центр кадра).
- `background.lowerShade` — затемнение нижнего левого угла; `background.godRays`, `background.brushed`, `background.fog` — лучи, диагональная текстура и туман.
- `timeline.ringsIntro` — длительность прорисовки крайних колец; `rings.speed` — скорость движения рисок; `rings.constructionOpacity` — пунктирная разметка «циркулем».
- `particles.rayLift` — подсветка пыли кольцами.
- `post.dofEnabled` — размытие (выключено, кадр чёткий); `post.chromaticAberration` — радиальная аберрация у краёв; `post.bloomIntensity` — блум.

Блики боке используют фрагмент [LYGIA `generative/random.glsl`](src/shaders/lygia-random.glsl); его [условия лицензии и уведомления](src/shaders/LYGIA-LICENSE.md) сохранены в репозитории. Применять этот код здесь разрешено с учётом подтверждённого некоммерческого статуса проекта; при изменении назначения нужно заново проверить лицензию.

## Основа для серии

Смена фреймворка не требуется: `src/runtime.js` отвечает за абсолютное время, паузу и точный `renderAt(t)` через интерфейс `update/render`, не импортируя Three.js. `src/scenes/catalog.js` задаёт единый формат **1920×1080 / 60 FPS** и план девяти видов. **Реализованы виды №1, 2, 8 и 9:** заставка ожидания (`src/scene.js`), фирменный фон (`src/brand-scene.js`), фотопауза (`src/photo-pause-scene.js`) и финал (`src/finale-scene.js`). Виды №3–7 остаются планами, а не фиктивными роликами.

`npm run typecheck` постепенно проверяет типы движка и описаний сцен без перевода шейдеров на другой язык. `npm run verify:render`, `npm run verify:brand` и `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` проверяют покадровый шов и наличие титра в экспортном canvas.

## Пульт показа и монтажная шкала

Курсор над заставкой больше не скрывается. Пульт внизу и кнопка ⚙ первой сцены появляются при движении мыши и уходят после 3,2 с бездействия; при работе с настройками или клавиатурной фокусировке не прячутся. **R** закрепляет/открепляет пульт.

- Кнопки **01 / 02 / 08 / 09** переключают готовые виды без перезагрузки страницы: стоп-кадр с титрами прежнего вида плавно растворяется в новом за 0,9 с.
- По умолчанию переход **ручной**. «Авто: вкл.» включает цепочку **01 → 02 → 08 → 09 → 01** после каждого цикла; для длительной речи оставьте авто выключенным. При записи переключение заблокировано.
- Ползунок прокручивает **текущий** цикл, рядом таймкод и шаг **−1 / +1 кадр** (стрелки клавиатуры). Перемотка ставит сцену на паузу. Поле «Цикл» изменяет длительность, корректируя фазу удержания, не качество рендера. Для финала минимум 12 с, чтобы вся фраза успела появиться.
- Пульт не входит в кадр, не добавляет звук и не меняет формат видео. **«● Цикл»** покадрово кодирует один цикл текущего вида; **«● Вся цепочка»** кодирует одним WebM 01 → 02 → 08 → 09 с теми же плавными переходами. Оба режима выводят каждый кадр по абсолютному времени и записывают строго **1920×1080 / 60 FPS**, даже если рендер идёт медленнее реального времени. Под пультом показывается прогресс и кнопка «Отменить». Запись цепочки всегда начинается с 01, даже если сейчас открыт другой вид, и заканчивается на 09; повторяющееся автоматическое воспроизведение в файл не входит. На время записи переключение и перемотка блокируются. Пауза — кнопка ▶/Ⅱ или пробел; на первой сцене сохраняется полная панель настроек ⚙.

Проверка управления и переходов: `npm run verify:operator`; покадрового WebM (15 кадров ускоренного тестового сценария, проверка каждого закодированного кадра и отмены): `npm run verify:offline`. Прежний тест записи в реальном времени: `npm run verify:chain` (нужны запущенный сервер и Chromium).

## Фирменный фон

Откройте `?scene=brand` (например, `http://localhost:5173/?scene=brand`). Здесь **только один символ циркуля и «Янтарный циркуль»**, без даты, кольцевого декора и искр. Фон подходит для речи, ужина и музыкальных сетов: лёгкое дыхание металла замыкается без затемнения через **24 с**. В нижнем пульте есть пауза, запись одного цикла WebM и кнопки 01/02/08/09; в экспорт они не попадают. [Контрольный кадр](docs/brand-background.jpg). Проверка `npm run verify:brand` проверяет сцепку, текст в canvas и покадровый шов.

## Фотопауза и финал

- `?scene=photo-pause` (№8): 24 с, один символ в углах видоискателя и титр «Фотопауза». Вся композиция едва дышит; первый и последний кадры совпадают. [Контрольный кадр](docs/photo-pause.jpg).
- `?scene=finale` (№9): 18 с; сначала светом открывается символ, затем посимвольно контуры и заливки «Янтарный циркуль», затем «История продолжается». В конце — затемнение перед следующим циклом. [Контрольный кадр](docs/finale.jpg).

Без дополнительных надписей и звука. У каждого вида собственный таймлайн, но тот же экспортный canvas 1920×1080 и покадровая запись WebM через кнопку «● Цикл». При необходимости проверить оба вида: `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` (сервер должен работать). Нажатие номера в панели переключает предпросмотр.

## Видео и проверка рендера
Первая заставка — логотип, «Янтарный циркуль», «Вечер ретроспектива», 20 ноября 2026 года.
Кадр всегда выводится в **1920×1080** с MSAA, SMAA и постобработкой; режим пониженного качества не предусмотрен.
Подпись и логотип рассчитываются по абсолютному времени кадра, а частицы создаются с фиксированным зерном случайности: перемотка и покадровый рендер воспроизводимы без «прогрева» анимации.

1. `npm ci` и `npm run dev` (оставить сервер запущенным).
2. Указать `CHROME=/путь/к/chrome` (Chromium/Chrome) или выполнить `scripts/setup-headless.sh` для портативного Chromium.
3. `npm test` — быстрые тесты таймлайна без браузера; `npm run verify:render` — проверка в браузере (ошибки, перемотка, шов и разрешение).
4. `FPS=60 OUT=out/frames npm run render:frames` — PNG-кадры одного цикла. Длительность и задержка считываются из текущих настроек браузера. Кадры нумеруются `f00000.png` и далее; последний кадр находится **перед** концом цикла.
5. `FPS=60 IN=out/frames OUT=out/logo-loop.mp4 npm run render:encode` — MP4 через установленный `ffmpeg`. Для монтажа без потерь используйте непосредственно PNG-последовательность.

Арт-дирекшен первой заставки, покадровый план и контрольные style frame: [`docs/animatic.md`](docs/animatic.md). Отбор GitHub-инструментов и эффектов с лицензиями и критериями внедрения: [`docs/github-motion-research.md`](docs/github-motion-research.md). Семь обзорных кадров можно переснять командой `OUT=docs/storyboard npm run render:storyboard` (они не заменяют финальный PNG-рендер).

`URL=http://localhost:5173/` можно переопределить для команд с браузером. Экспорт из панели настроек и пульта теперь использует WebCodecs VP9 и [Mediabunny](https://github.com/Vanilagy/mediabunny) (MPL-2.0) для WebM: **40 Мбит/с, фиксированные 60 FPS**, без звука и пониженного пресета. Нужен браузер с WebCodecs (например, актуальный Chrome/Edge и защищённый контекст HTTPS или localhost). Стандартная цепочка — 4878 кадров / 81,3 с видео; обработка может занять существенно больше времени и потребовать несколько сотен МБ свободной памяти для готового файла. Не закрывайте вкладку до завершения или отмены.
На шве есть короткий полностью тёмный участок: он скрывает непрерывное движение фонового шума и колец. `verify:render` сравнивает реальные пиксели первого и последнего кадра при 60 FPS; для стандартных настроек они совпадают. При изменении длительностей фаз проверьте шов заново.
