# circle.animaation.proto-1

Зацикленная 3D-анимация золотого логотипа (three.js + postprocessing).

## Запуск

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # сборка в dist/

При первом открытии отображается тёмный экран подготовки сцены. Он исчезает **после первого WebGL-кадра и загрузки шрифтов**, не попадая в видеозапись. Если модули не загрузились или WebGL недоступен, вместо белой страницы появится сообщение об ошибке с кнопкой «Повторить загрузку». Проверка сценария отказа: `npm run verify:loader` (контрольный кадр: [`docs/loader-preview.jpg`](docs/loader-preview.jpg)).

**Если файлы приложения не загружаются:** не открывайте исходный `index.html` напрямую из файлового менеджера — используйте `npm ci` и `npm run dev`. Для размещения на сайте выполните `npm run build` и публикуйте содержимое `dist/`, а не исходники. Готовая сборка работает и в корне сайта, и в подпапке; адрес подпапки должен оканчиваться `/`. Сообщение об ошибке показывает путь недоступного обязательного файла без параметров URL. Отказ загрузки сторонней аналитики и других необязательных ресурсов не скрывает заставку.

## 01 · Стартовое интро

Первый ролик — открытие вечера, а не экран ожидания. Его можно открыть по `?scene=intro` (старый адрес `?scene=waiting` тоже работает). Вступление начинается с золотого света и построительной точки; камера подъезжает к слегка повёрнутому символу, свет раскрывается лучами и коротким бликом, а знак поворачивается к зрителю. Когда появляются надписи, свет уступает им место. На готовой композиции нет фоновых копий контура или пунктирного кольца вокруг логотипа: расходящиеся контуры сохранены для фирменного фона №02 и родственных сцен. Угловые огни и в интро, и в фоновом ролике остаются только в двух местах — слева сверху и справа снизу.

Световая точка намечает окружность → передаёт движение контуру циркуля → проявление из тени → удержание → последовательный уход даты, подзаголовка и названия → уход золота и обратная прорисовка → тёмный шов. Буквы последовательно гравируются контуром и заполняются золотом; под знаком остаются название, подзаголовок и дата. На удержании фон, пыль и крайние кольца продолжают двигаться.

Цикл интро длится **15,3 с**, а полностью собранная композиция остаётся читаемой около **5,1 с** до начала ухода. Длительности фаз меняются в панели настроек. Другие готовые сцены сохраняют общий золотой язык, последовательность титров и обратный уход, но без стартового светового акцента интро. Время анимации не замедляется при падении частоты кадров.

## Настройки
⚙ в правом верхнем углу (или клавиша S). Пробел — пауза. Двойной клик по ползунку — сброс.
- **Экспорт JSON** — копировать/скачать текущие настройки.
- **Импорт** — вставить JSON и «Применить».
- **Сброс** — значения первой сцены из `src/scenes/waiting.js` (`WAITING_DEFAULTS`).

Чтобы присланный JSON стал значением по умолчанию, перенесите его в `WAITING_DEFAULTS` в `src/scenes/waiting.js` (`src/config.js` по-прежнему экспортирует совместимый `DEFAULTS`).
После обновления визуальных значений по умолчанию нажмите **Сброс** в панели: ранее сохранённые в браузере настройки продолжают действовать до сброса.

### Основные группы параметров
- `logo.depth`, `logo.bevel`, `logo.outlineWidthPx` — толщина логотипа, скос и контур (логотип растёт во время проявления).
- `lights.topGlow` — свечение над логотипом (центр кадра).
- `background.lowerShade` — затемнение нижнего левого угла; `background.godRays`, `background.brushed`, `background.fog` — лучи, диагональная текстура и туман.
- `timeline.ringsIntro` — длительность прорисовки крайних колец; `rings.speed` — скорость движения рисок; `rings.constructionOpacity` — пунктирная разметка «циркулем».
- `particles.rayLift` — подсветка пыли кольцами.
- `post.dofEnabled` — размытие (выключено, кадр чёткий); `post.chromaticAberration` — радиальная аберрация у краёв; `post.bloomIntensity` — блум.

Блики боке используют фрагмент [LYGIA `generative/random.glsl`](src/shaders/lygia-random.glsl); его [условия лицензии и уведомления](src/shaders/LYGIA-LICENSE.md) сохранены в репозитории. Применять этот код здесь разрешено с учётом подтверждённого некоммерческого статуса проекта; при изменении назначения нужно заново проверить лицензию.

## Основа для серии

Смена фреймворка не требуется: `src/runtime.js` отвечает за абсолютное время, паузу и точный `renderAt(t)` через интерфейс `update/render`, не импортируя Three.js. `src/scenes/catalog.js` задаёт единый формат **1920×1080 / 60 FPS** и план девяти видов. **Реализованы виды №1, 2, 8 и 9:** интро (`src/scene.js`), фирменный фон (`src/brand-scene.js`), фотопауза (`src/photo-pause-scene.js`) и финал (`src/finale-scene.js`). Виды №3–7 остаются планами, а не фиктивными роликами.

`npm run typecheck` постепенно проверяет типы движка и описаний сцен без перевода шейдеров на другой язык. `npm run verify:render`, `npm run verify:brand`, `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` проверяют покадровый шов, расположение текста и фазы анимации. `npm run verify:intro` проверяет свет и отсутствие фоновых контуров в интро; `npm run verify:motion` сравнивает реальные пиксели движущегося фона и контурных волн во втором ролике.

## Пульт показа и монтажная шкала

Курсор над заставкой больше не скрывается. Пульт внизу и кнопка ⚙ первой сцены появляются при движении мыши и уходят после 3,2 с бездействия; при работе с настройками или клавиатурной фокусировке не прячутся. **R** закрепляет/открепляет пульт.

- Кнопки **01 / 02 / 08 / 09** переключают готовые виды без перезагрузки страницы: стоп-кадр с титрами прежнего вида плавно растворяется в новом за 0,9 с.
- По умолчанию переход **ручной**. «Авто: вкл.» включает цепочку **01 → 02 → 08 → 09 → 01** после каждого цикла; для длительной речи оставьте авто выключенным. При записи переключение заблокировано.
- Ползунок прокручивает **текущий** цикл, рядом таймкод и шаг **−1 / +1 кадр** (стрелки клавиатуры). Перемотка ставит сцену на паузу. Поле «Цикл» изменяет длительность, корректируя фазу удержания, не качество рендера. Для видов 02, 08 и 09 минимум 12,5 с, чтобы титры успели собраться и остаться читаемыми.
- Пульт не входит в кадр, не добавляет звук и не меняет формат видео. **«● Цикл»** сохраняет один цикл текущего вида; **«● Вся цепочка»** записывает одним WebM 01 → 02 → 08 → 09 с теми же плавными переходами. Запись цепочки всегда начинается с 01, даже если сейчас открыт другой вид, и заканчивается на 09; повторяющееся автоматическое воспроизведение в файл не входит. На время записи переключение и перемотка блокируются. Пауза — кнопка ▶/Ⅱ или пробел; на первой сцене сохраняется полная панель настроек ⚙.

Проверка управления и переходов: `npm run verify:operator`; единого WebM (ускоренный прогон без изменения художественных defaults): `npm run verify:chain` (нужны запущенный сервер и Chromium).

## Фирменный фон

Откройте `?scene=brand` (например, `http://localhost:5173/?scene=brand`). По центру расположен символ циркуля, **название «Янтарный циркуль» — под ним**, без даты и дополнительных строк. Световая точка и контур собирают композицию в общем стиле с интро; золотой свет, фактура, кольца, частицы и расходящиеся контуры непрерывно оживляют удержание. Знак крупнее, титр стоит в нижней трети кадра, а эхо-контуры рождаются уже больше знака и не дублируют его силуэт. В конце текст гаснет, логотип уходит в тень, а точка отматывает контур и построительную окружность к исходной точке. Полный цикл — **24 с**. В нижнем пульте есть пауза, запись одного цикла WebM и кнопки 01/02/08/09; в экспорт они не попадают. [Контрольный кадр](docs/brand-background.jpg). Проверка `npm run verify:brand` проверяет оформление, фазы, текст в canvas и покадровый шов.

## Фотопауза и финал

- `?scene=photo-pause` (№8): 24 с, тот же фирменный фон и анимация, но с рамкой видоискателя вокруг символа и выровненным под ним титром «Фотопауза». [Контрольный кадр](docs/photo-pause.jpg).
- `?scene=finale` (№9): 18 с; после прорисовки символа под ним посимвольно собираются «Янтарный циркуль» и «История продолжается». Затем текст и символ уходят в обратном порядке. [Контрольный кадр](docs/finale.jpg).

Без дополнительных надписей и звука. У каждого вида собственный таймлайн, но тот же экспортный canvas 1920×1080 и запись WebM через кнопку «Записать цикл». При необходимости проверить оба вида: `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` (сервер должен работать). Нажатие номера в панели переключает предпросмотр.

## Видео и проверка рендера
Первая заставка — логотип, «Янтарный циркуль», «Вечер ретроспектива», 20 ноября 2026 года.
Кадр всегда выводится в **1920×1080** с MSAA, SMAA и постобработкой; режим пониженного качества не предусмотрен.
Подпись и логотип рассчитываются по абсолютному времени кадра, а частицы создаются с фиксированным зерном случайности: перемотка и покадровый рендер воспроизводимы без «прогрева» анимации.

1. `npm ci` и `npm run dev` (оставить сервер запущенным).
2. Указать `CHROME=/путь/к/chrome` (Chromium/Chrome) или выполнить `scripts/setup-headless.sh` для портативного Chromium.
3. `npm test` — быстрые тесты без браузера; `npm run verify:render` — проверка браузерного рендера (ошибки, перемотка, шов и разрешение). `npm run verify:motion` проверяет настоящие пиксели волн, фона и обратной орбиты, а также отсутствие волн в области титров; при `OUT=out/motion` сохраняет контрольные кадры входа, удержания и обратного ухода. `npm run verify:caption` сравнивает титры предпросмотра с экспортным canvas на контрольных кадрах, включая частичное проявление букв (нужен запущенный dev-сервер). `npm run verify:caption:export` дополнительно проверяет композит с настоящим WebGL в видах 01 и 09; на программном рендерере эти тесты могут выполняться несколько минут.
4. `FPS=60 OUT=out/frames npm run render:frames` — PNG-кадры одного цикла. Длительность и задержка считываются из текущих настроек браузера. Кадры нумеруются `f00000.png` и далее; последний кадр находится **перед** концом цикла.
5. `FPS=60 IN=out/frames OUT=out/logo-loop.mp4 npm run render:encode` — MP4 через установленный `ffmpeg`. Для монтажа без потерь используйте непосредственно PNG-последовательность.

Арт-дирекшен интро, покадровый план и контрольные style frame: [`docs/animatic.md`](docs/animatic.md). Отбор GitHub-инструментов и эффектов с лицензиями и критериями внедрения: [`docs/github-motion-research.md`](docs/github-motion-research.md). Семь обзорных кадров можно переснять командой `OUT=docs/storyboard npm run render:storyboard` (они не заменяют финальный PNG-рендер).

`URL=http://localhost:5173/` можно переопределить для команд с браузером. Экспорт видео из панели настроек — WebM в реальном времени; он зависит от производительности браузера и не заменяет точный покадровый рендер.
Все готовые виды завершаются обратной прорисовкой и коротким тёмным участком на шве. При паузе короче 0,45 с возврат по окружности пропускается, чтобы оставить тёмный шов. Во время удержания фон продолжает двигаться; во втором ролике контурные волны повторяются с затуханием. Проверки сравнивают реальные пиксели первого и последнего кадра при 60 FPS; для стандартных настроек они совпадают. При изменении длительностей фаз проверьте шов заново.

## Дальнейшая серия
Виды №1, 2, 8 и 9 готовы. В дальнейшем на общей визуальной основе планируются №3 «Проект мечты», №4 «Партнёры вечера», №5 «Янтарный циркуль: помним всё», №6 «ТЗ с подвохом», №7 «Проектировщик объясняет». Их сценарии и тексты уточняются отдельно.
