# circle.animaation.proto-1

Зацикленная 3D-анимация золотого логотипа (three.js + postprocessing).

## Запуск

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # сборка в dist/

При первом открытии отображается тёмный экран подготовки сцены. Он исчезает **после первого WebGL-кадра и загрузки шрифтов**, не попадая в видеозапись. Если модули не загрузились или WebGL недоступен, вместо белой страницы появится сообщение об ошибке с кнопкой «Повторить загрузку». Проверка сценария отказа: `npm run verify:loader` (контрольный кадр: [`docs/loader-preview.jpg`](docs/loader-preview.jpg)).

**Если файлы приложения не загружаются:** не открывайте исходный `index.html` напрямую из файлового менеджера — используйте `npm ci` и `npm run dev`. Для размещения на сайте выполните `npm run build` и публикуйте содержимое `dist/`, а не исходники. Готовая сборка работает и в корне сайта, и в подпапке; адрес подпапки должен оканчиваться `/`. Сообщение об ошибке показывает путь недоступного обязательного файла без параметров URL. Отказ загрузки сторонней аналитики и других необязательных ресурсов не скрывает заставку.

## 01 · Стартовое интро

Первый ролик — открытие вечера, а не экран ожидания. Его можно открыть по `?scene=intro` (старый адрес `?scene=waiting` тоже работает). Вступление начинается с разметки и двух построительных точек; камера подъезжает к обращённому прямо символу, свет раскрывается лучами и коротким бликом; знак не вращается в 3D. Когда появляются надписи, лучи становятся мягче, но остаются в кадре. На готовой композиции нет фоновых копий контура или пунктирного кольца вокруг логотипа: расходящиеся контурные волны сохранены только для фотопаузы №08. Угловые огни и в интро, и в фоновом ролике остаются только в двух местах — слева сверху и справа снизу.

Крупное центральное перекрестие и угловые перекрестия размечают композицию → две противоположные световые точки замыкают окружность → одна передаёт движение контуру циркуля → проявление из тени → удержание → последовательный уход даты, подзаголовка и названия → опускание знака → уход боковых кругов → обратная обводка знака → две точки сворачивают окружность, исчезает разметка → тёмный шов. Продолжительность всего обратного выхода задаётся фазой «Уход»; при короткой фазе все этапы проходят быстрее. Штатные титры по умолчанию плавно проявляются целиком без обводки; под знаком остаются название, подзаголовок и дата. На удержании фон, пыль и крайние кольца продолжают двигаться.

Цикл интро по умолчанию длится **19,1 с**. Сначала точка рисует круг в центре, затем проявляется логотип, рисуются два боковых круга, знак поднимается и появляются надписи. Полностью собранная композиция остаётся читаемой около **5 с** до начала ухода. Длительности фаз меняются в панели настроек. Другие готовые сцены сохраняют общий золотой язык, последовательность титров и обратный уход, но без стартового светового акцента интро. Время анимации не замедляется при падении частоты кадров.

### Первый кинематографичный проход интро

В интро по умолчанию включены более мягкие асимметричные пучки и медленные
более контрастные студийные отражения на золоте; угловые засветки и частицы приглушены, чтобы знак и титры читались выразительнее. Чтобы сравнить с прежним видом, откройте ⚙ →
«Логотип» и выключите «Кинематографичный свет и металл». Настройка сохраняется
в JSON сцены и действует одинаково в предпросмотре и в покадровом экспорте;
в остальных сценах она по умолчанию выключена. Свет рассчитывается от абсолютного
времени и не меняет длительность, последовательность или шов цикла. Это первый
художественный проход, а не гарантия фотореализма или результата на каждом экране.
Техническая браузерная проверка: `npm run verify:cinematic` при запущенном сервере.

### Металлическое название

В интро добавлен золотой градиент с мягкими светлыми и тёмными отражениями на
штатном названии. Его можно выключить в ⚙ → «Надписи» → «Название: металлическое
золото». Свой цвет названия имеет приоритет и отключает градиент; его возврат к
исходному цвету снова включает эффект. Цвета повторяются в экспортном композите.
В остальных сценах настройка по умолчанию выключена; это имитация металла, не
объёмная 3D-геометрия.

### Фактура фона интро

В разделе ⚙ → «Фон и свет» ползунок «Текстура тёмного камня» управляет
матовой графитовой поверхностью с мелкой зернистостью; ноль отключает её.
Основа сгенерирована ИИ по мотивам референса и не содержит надписей или логотипа.
Параметр сохраняется в JSON (под прежним ключом `fabricTexture`), попадает в MP4
и по умолчанию включён только в интро. Перед показом и экспортом приложение ждёт
загрузки изображения; при ошибке используется упрощённая процедурная фактура.

## Настройки
⚙ в правом верхнем углу (или клавиша S) доступна в каждой сцене. Пробел — пауза,
двойной клик по ползунку — сброс одного поля.

- **Вкладки 01 / 02 / 08 / 09** переключают сцену вместе с её собственным набором
  параметров: правка фонового ролика не меняет интро и наоборот.
- **Экспорт сцены** и **Экспорт проекта** выдают JSON одной сцены или всех четырёх
  сразу; «Копировать» кладёт его в буфер, «Скачать .json» сохраняет файл.
- **Импорт** принимает и JSON сцены (частичный: недостающие ключи берутся из
  умолчаний), и файл проекта с объектом `scenes`.
- **Сброс сцены** возвращает умолчания только этой сцены.
- В разделе **«Логотип»** есть «Янтарный срез и подсветка» (`logo.amber`):
  тёплый свет на боковых гранях знака и мягкое свечение за ним. Ноль возвращает
  прежний вид и сохраняется в JSON; старые файлы без ключа получают значение по
  умолчанию.
- В разделе **«Фон и свет»** отдельно включаются лучи от кругов, туман,
  диагональная текстура, зерно, виньетка фона, затемнение угла и сетка.
  Выключатель сохраняет заданную интенсивность для последующего включения;
  старые настройки оставляют эти эффекты включёнными. Это выключатели именно
  фона: верхние лучи, подсветка пыли и общая постобработка управляются отдельно.
- Настройки хранятся в браузере отдельно для каждой сцены
  (`circle-anim-settings-v2:<сцена>`); старый общий ключ читается один раз как
  настройки интро.

Чтобы присланный JSON стал новым умолчанием, перенесите его значения в
`WAITING_DEFAULTS` (`src/scenes/waiting.js`) для интро или в
`createSharedSceneConfig` (`src/scenes/shared-visuals.js`) для фоновых сцен, а затем
нажмите «Сброс сцены» — сохранённые в браузере значения перекроют код до сброса.

Штатные титры по умолчанию мягко проявляются целиком без обводки. В инспекторе остаётся доступен старый вариант обрисовки: он использует контуры глифов, а если контур шрифта недоступен — маску.

Проверки кадра: `npm run verify:typography` (ритм, контраст строк, толщина
линий) и `npm run verify:gradients` (полосы на тёмных градиентах и совпадение
яркости титра в превью и в кадре).

Вертикальный ритм блока рассчитан на зал: обе линии-разделителя стоят так, что промежутки вокруг них близки, дата крупнее прежней (1,95% ширины кадра) и не сливается с фоном, а подзаголовок идёт с интервалом 0,22em вместо 0,32em — слово больше не распадается на буквы. Штатные значения живут в `WAITING_DEFAULTS.typography` и переменных `src/styles.css`; сохранённые старые настройки остаются как есть. Проверка — `npm run verify:typography`.

Титр рисуется внутри постобработки: он попадает в кадр отдельным проходом до тонмаппинга, получает общее сведение, сглаживание и дизеринг, но не размывается блумом, аберрацией и глубиной резкости. Поэтому предпросмотр и экспорт идут одним путём, а DOM-слой нужен только редактору: рамки, измерения и подсказки. При открытом редакторе кадр всё равно собирается с запечённым текстом, и надпись не теряется в записи.

### 08 · Фотопауза
Логотип по умолчанию расположен в центре; круговая надпись доступна, но по умолчанию выключена,
а у краёв кадра находятся четыре тонких уголка видоискателя. Сначала плавно раскрывается отключаемая апертура объектива, затем появляется контур знака. Логотип сперва неподвижно прорисовывается контуром, затем плавно начинает вращаться вокруг вертикальной оси, проходя через вид ребром и лицом; скорость задаётся числом оборотов за 20 секунд (0 выключает вращение). Надпись и уголки
рисуются внутри сцены, поэтому входят и в запись. В разделе «Круговая надпись и рамка» можно
изменить текст, количество повторов, размер, радиус, скорость вращения, цвет,
прозрачность, параметры апертуры, радиус пунктирного круга, размеры и мягкую пульсацию уголков. Шрифт выбирается в разделе «Типографика».
При первом запуске прежнее стандартное положение логотипа 0,86 автоматически
переносится в центр (0); остальные сохранённые параметры не сбрасываются.
Другие значения положения сохраняются, а после переноса высоту можно настроить заново. Прежний стандартный масштаб 0,47 один раз заменяется на 0,58; остальные сохранённые размеры не меняются.
При крайних значениях размера логотипа и радиуса надписи возможно пересечение.

### 09 · Финал
Вход выполнен в стиле интро: разметка, окружность с двумя точками, знак,
боковые круги и подъём перед надписями. На выходе название исчезает, знак
возвращается к центру, удаляется и стирается вместе с окружностью. Надпись
«История продолжается» перемещается в центр, остаётся на тёмном фоне и плавно
стирается последней. Надпись, её цвет, размер и смещение можно изменить.
В «Финальном уходе» регулируются глубина и конечный масштаб, а общая длительность
последовательности задаётся фазой «Уход» в таймлайне. В настройках «Финальный уход» отдельно задаются длительности прорисовки фразы, её перемещения к центру, удержания и стирания. Если этапы не помещаются в отведённое время, они автоматически сокращаются; увеличьте удержание или фазу «Уход» на таймлайне.

### Основные группы параметров
- `intro.cornerDuration`, `intro.liftDuration`, `intro.titleDelay` — длительность появления двух боковых кругов, подъёма знака и пауза до титров (только сцена 01). Если сделать эти интервалы слишком длинными или удержание слишком коротким, титры могут не успеть появиться до ухода.
- `typography.font` — шрифт титров для текущей сцены: Cormorant Garamond, Playfair Display, Prata, PT Serif, Manrope или Unbounded. Выбор сохраняется в JSON; шрифты входят в сборку.
- `logo.depth`, `logo.bevel`, `logo.outlineWidthPx` — толщина логотипа, скос и контур (логотип растёт во время проявления).
- `lights.topGlow` — свечение над логотипом (центр кадра).
- `topIllumination.raysEnabled`, `raysIntensity`, `raysSpeed`, `raysColor` — независимое включение, яркость, скорость и цвет верхних лучей в каждой сцене. Лучи следуют центру логотипа; их настройки не выключают ореол и освещение металла.
- `background.lowerShade` — затемнение нижнего левого угла; `background.godRays`, `background.brushed`, `background.fog` — лучи, диагональная текстура и туман.
- `timeline.ringsIntro` — длительность прорисовки крайних колец; `rings.speed` — скорость движения рисок; `rings.constructionOpacity` — пунктирная разметка «циркулем».
- `particles.rayLift` — подсветка пыли кольцами.
- `post.dofEnabled` — размытие (выключено, кадр чёткий); `post.chromaticAberration` — аберрация: одинаковое смещение красного и синего каналов по всему кадру, не радиальная (в углах не усиливается); `post.bloomIntensity` — блум.
- `post.ditherEnabled`, `post.dither` — финальный дизеринг в «Постобработке». Он включён по
  умолчанию (1.0 LSB) и убирает полосы на тёмных градиентах после H.264; зерно
  остаётся отдельным анимированным слоем.
- `camera.holdDolly` — медленный подъезд камеры на удержании: доля кадра
  (0–0,06). По умолчанию 0 — прежний неподвижный кадр; движение считается по
  абсолютному времени, поэтому перемотка и детерминизм не страдают.
- `camera.parallax` — параллакс слоёв (0–3, по умолчанию 1): фон, кольца и пыль
  смещаются на 2–4 px относительно знака. Знак и титр не двигаются; смещение
  периодично по циклу, поэтому шов остаётся прежним.
- **Качество** — рядом с «Мастер» в пульте: «Черновик» (без MSAA, тише блум),
  «Превью» и «Мастер» (полный кадр). Меняется только стоимость сглаживания и
  блума; композиция и тайминги те же, поэтому записывать можно с любым
  пресетом. Выбор запоминается в браузере.
- **Мастер-кадр** — переключатель «Мастер» в пульте: 1920×1080 или 3840×2160.
  Меняется только пиксельная сетка: композиция задана в долях кадра, а титр,
  экспорт и битрейт следуют за профилем. Выбор запоминается в браузере; экспорт
  4K требует заметно больше памяти и времени.

Блики боке используют фрагмент [LYGIA `generative/random.glsl`](src/shaders/lygia-random.glsl); его [условия лицензии и уведомления](src/shaders/LYGIA-LICENSE.md) сохранены в репозитории. Применять этот код здесь разрешено с учётом подтверждённого некоммерческого статуса проекта; при изменении назначения нужно заново проверить лицензию.

## Основа для серии

Смена фреймворка не требуется: `src/runtime.js` отвечает за абсолютное время, паузу и точный `renderAt(t)` через интерфейс `update/render`, не импортируя Three.js. `src/scenes/catalog.js` задаёт единый формат **1920×1080 / 60 FPS** и план девяти видов. **Реализованы виды №1, 2, 8 и 9:** интро (`src/scene.js`), фирменный фон (`src/brand-scene.js`), фотопауза (`src/photo-pause-scene.js`) и финал (`src/finale-scene.js`). Виды №3–7 остаются планами, а не фиктивными роликами.

`npm run typecheck` постепенно проверяет типы движка и описаний сцен без перевода шейдеров на другой язык. `npm run verify:render`, `npm run verify:brand`, `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` проверяют покадровый шов, расположение текста и фазы анимации. `npm run verify:intro` проверяет свет и отсутствие фоновых контуров в интро; `npm run verify:motion` сравнивает реальные пиксели движущегося фона; с `SCENE=photo-pause` проверяет также волны фотопаузы.

## Пульт показа и монтажная шкала

Курсор над заставкой больше не скрывается. Пульт внизу появляется при движении мыши и уходит после 3,2 с бездействия; кнопка ⚙ остаётся видимой во всех готовых сценах, приглушаясь в простое; при работе с настройками или клавиатурной фокусировке не прячутся. **R** закрепляет/открепляет пульт.

- Кнопки **01 / 02 / 08 / 09** переключают готовые виды без перезагрузки страницы: стоп-кадр с титрами прежнего вида плавно растворяется в новом (по умолчанию за 0,9 с).
- По умолчанию переход **ручной**. «Авто: вкл.» включает цепочку **01 → 02 → 08 → 09 → 01** после каждого цикла; для длительной речи оставьте авто выключенным. При записи переключение заблокировано.
- Ползунок прокручивает **текущий** цикл, рядом таймкод и шаг **−1 / +1 кадр** (стрелки клавиатуры). Перемотка ставит сцену на паузу. Поле «Цикл» изменяет длительность, корректируя фазу удержания, не качество рендера. Для видов 02, 08 и 09 минимум 12,5 с, чтобы титры успели собраться и остаться читаемыми.
- Пульт не входит в кадр, не добавляет звук и не меняет формат видео. **«● Цикл»** сохраняет один цикл текущего вида; **«● Вся цепочка»** записывает одним MP4 01 → 02 → 08 → 09 с теми же плавными переходами. Запись цепочки всегда начинается с 01, даже если сейчас открыт другой вид, и заканчивается на 09; повторяющееся автоматическое воспроизведение в файл не входит. Длительность входа настраивается отдельно в каждой сцене в разделе «Переход в эту сцену»; 0 означает склейку. Для цепочки длительность лучше задавать короче самой входящей сцены. На время записи переключение и перемотка блокируются. Пауза — кнопка ▶/Ⅱ или пробел; панель настроек ⚙ доступна во всех четырёх сценах.

Проверка управления и переходов: `npm run verify:operator`; единого MP4 (ускоренный прогон без изменения художественных defaults): `npm run verify:chain` (нужны запущенный сервер и Chromium). Тест временно сокращает все четыре цикла и записывает 24 кадра в 1920×1080; проверяет переходы, фактическую видеодорожку и декодирует пять выбранных кадров. Это не просмотр нормального ролика, а переходы в коротком тесте обрываются концом сцены. В software WebGL прогон может занимать несколько минут.

## Фирменный фон

Откройте `?scene=brand`. По умолчанию знак и построительная окружность находятся в центре; вокруг вращается надпись «Янтарный циркуль». Надпись настраивается отдельно в свойствах элемента и разделе «Круговая надпись и рамка», а прежний отдельный титр по умолчанию скрыт и может быть включён снова. Волн от логотипа в этой сцене нет. Сохранённое прежнее стандартное положение знака переносится в центр один раз; пользовательские положения и изменённый титр сохраняются. Цикл — 24 с; композиция и текст входят в видео.

## Фотопауза и финал

- `?scene=photo-pause` (№8): 24 с, тот же фирменный фон и анимация, с опциональной (по умолчанию выключенной) круговой надписью «Фотопауза», пунктиром и мягко движущимися к центру уголками видоискателя.
- `?scene=finale` (№9): 18 с; после прорисовки символа под ним посимвольно собираются «Янтарный циркуль» и «История продолжается». Затем текст и символ уходят в обратном порядке. [Контрольный кадр](docs/finale.jpg).

Без дополнительных надписей и звука. У каждого вида собственный таймлайн, но тот же экспортный canvas 1920×1080 и запись MP4 через кнопку «Записать цикл». При необходимости проверить оба вида: `SCENE=photo-pause npm run verify:priority` и `SCENE=finale npm run verify:priority` (сервер должен работать). Нажатие номера в панели переключает предпросмотр.

## Интервалы букв

В разделе «Типографика» можно отдельно задать межбуквенный интервал названия,
подзаголовка и даты (в долях размера шрифта, em). Настройки сохраняются отдельно
для каждой сцены и применяются как к предпросмотру, так и к MP4. В сценах,
где строка не используется, соответствующий ползунок скрыт. Круговая надпись
02/08 по-прежнему настраивается отдельно; новые интервалы на неё не влияют.
Старые конфигурации получают прежние значения интервалов. Для каждой добавленной
надписи в её свойствах доступен собственный интервал от 0 до 0,6 em; он
сохраняется при дублировании и поддерживает отмену/повтор. По умолчанию он равен
нулю. Автоподгонка учитывает изменившуюся ширину строки.

В разделе «Надписи» можно отдельно включить **«Вписать в поля»** для названия,
подзаголовка и даты: длинная строка уменьшается по ширине с учётом её горизонтального
положения и ориентировочных полей 5%. Исходный размер не меняется; при отключении
возвращается прежний. Подгонка выключена по умолчанию и не переносит текст на новую строку. Для
собственной надписи её можно отдельно включить в свойствах выбранного слоя;
она сохраняется при дублировании и поддерживает отмену/повтор. На круговую
надпись подгонка не распространяется. Она не
гарантирует читаемость: длинная строка может стать слишком мелкой, а при положении
центра за пределами поля вписать её полностью невозможно.

## Режиссёрская подача интро

Переключатель «Логотип» → **«Интро: режиссёрская подача движения»** включает
плавный разгон и передачу света от центральной орбиты, мягкую задержку правого круга со связанным светом и частицами, а также плавно
вводит пульсацию знака после его остановки. Акцент раскрытия немного усилен;
штатное название слегка поднимается при появлении, а мягкое отражение проходит
по его металлической поверхности синхронно с бликом знака. Посадка применяется
только к штатному времени и стилю «fade»; стили «fade-up» и «draw» не меняются. При своём цвете или собственном времени титра проход отключён.
Переключатель не меняет длительность цикла, сохраняется в JSON и действует
только в интро. Выключение возвращает синхронное появление кругов и прежнюю
пульсацию; параметры света, частиц и длительностей остаются редактируемыми.

## Материал золота

Окружение для металла строится процедурно (`src/studio-environment.js`): большой
фронтальный софтбокс, верхний ключевой свет, две узкие боковые полосы и нижний
отражатель. Это заменило стандартную комнату three.js и дало вытянутые блики на
фаске; теневая сторона знака остаётся тёплой, а не серой. Окружение не зависит от
сохранённых настроек, поэтому одинаково во всех сценах и в экспорте.

В интро отдельный параметр **«Студийный свет и отражения»** усиливает различия
реальных скосов по направлению света и добавляет мягкое отражение на лицевых гранях. Значение 0 отключает новый эффект; он не
меняет геометрию или тайминг и по умолчанию выключен в остальных сценах. Для
видимых кромок значение «Скос кромок» должно быть больше нуля.

В разделе «Логотип» параметр **«Объём граней золота»** добавляет мягкое
различие освещения лицевой поверхности и фасок. Ноль сохраняет прежний вид.
Настройка хранится отдельно для каждой сцены и входит в JSON и экспорт; в
утверждённых фоновых сценах 02 и 08 по умолчанию она выключена.

## Макет «Спонсоры и партнёры»

На пульте доступна сцена **04 «Спонсоры»**: бордово-золотая заставка по
референсу, две компании организатора и два партнёра в одной строке. Сейчас это
именно макет: названия — текстовые заглушки, не официальные логотипы. Тексты
изменяются через ⚙ → «Спонсоры и партнёры» и сохраняются отдельно от других
сцен. Рамка, занавес, ветвь и циркуль нарисованы графикой и анимированы; изображением остаётся только текстура фона. В настройках можно отключить отдельные украшения и изменить интенсивность движения. Добавление изображений логотипов и визуальное редактирование слоёв этой
сцены пока не реализованы. Сцену можно записать отдельно; в существующую
цепочку 01 → 02 → 08 → 09 она пока не включена.

## Видео и проверка рендера
Первая заставка — логотип, «Янтарный циркуль», «Вечер ретроспектива», 20 ноября 2026 года.
Кадр всегда выводится в **1920×1080** с MSAA, SMAA и постобработкой; режим пониженного качества не предусмотрен.
Подпись и логотип рассчитываются по абсолютному времени кадра, а частицы создаются с фиксированным зерном случайности: перемотка и покадровый рендер воспроизводимы без «прогрева» анимации.

1. `npm ci` и `npm run dev` (оставить сервер запущенным).
2. Указать `CHROME=/путь/к/chrome` (Chromium/Chrome) или выполнить `scripts/setup-headless.sh` для портативного Chromium.
3. `npm test` — быстрые тесты без браузера; `npm run verify:render` — проверка браузерного рендера (ошибки, перемотка, шов и разрешение). `npm run verify:motion` проверяет настоящие пиксели волн, фона и обратной орбиты, а также отсутствие волн в области титров; при `OUT=out/motion` сохраняет контрольные кадры входа, удержания и обратного ухода. `npm run verify:caption` сравнивает титры предпросмотра с экспортным canvas на контрольных кадрах, включая частичное проявление букв (нужен запущенный dev-сервер). `npm run verify:caption:export` дополнительно проверяет композит с настоящим WebGL в видах 01 и 09; на программном рендерере эти тесты могут выполняться несколько минут.
4. `FPS=60 OUT=out/frames npm run render:frames` — PNG-кадры одного цикла. Длительность и задержка считываются из текущих настроек браузера. Кадры нумеруются `f00000.png` и далее; последний кадр находится **перед** концом цикла.
5. `FPS=60 IN=out/frames OUT=out/logo-loop.mp4 npm run render:encode` — MP4 через установленный `ffmpeg`. Для монтажа без потерь используйте непосредственно PNG-последовательность.

Арт-дирекшен интро, покадровый план и контрольные style frame: [`docs/animatic.md`](docs/animatic.md). Отбор GitHub-инструментов и эффектов с лицензиями и критериями внедрения: [`docs/github-motion-research.md`](docs/github-motion-research.md). Семь обзорных кадров можно переснять командой `OUT=docs/storyboard npm run render:storyboard` (они не заменяют финальный PNG-рендер).

`URL=http://localhost:5173/` можно переопределить для команд с браузером. Экспорт одного цикла и всей цепочки создаёт MP4 покадрово: каждый кадр рассчитывается с фиксированным временем и проверяется в готовом файле. Скорость компьютера влияет только на время экспорта, а не на пропуск кадров. Для экспорта нужны WebCodecs и поддержка H.264 (актуальный Chrome/Edge, HTTPS или localhost); при отсутствии поддержки файл не создаётся. Экспорт можно отменить. Готовое видео временно хранится в памяти браузера, поэтому длинные ролики требуют достаточно памяти.
Все готовые виды завершаются обратной прорисовкой и коротким тёмным участком на шве. При паузе короче 0,45 с возврат по окружности пропускается, чтобы оставить тёмный шов. Во время удержания фон продолжает двигаться; только в фотопаузе волны от силуэта повторяются с затуханием. Проверки сравнивают реальные пиксели первого и последнего кадра при 60 FPS; для стандартных настроек они совпадают. При изменении длительностей фаз проверьте шов заново.

## Редактирование на кадре

Кнопка «Редактировать» в левом верхнем углу ставит ролик на паузу и показывает
собранную композицию. Перетащите рамку логотипа, названия, подзаголовка или даты; потяните за
квадратик на рамке, чтобы изменить размер. Клавиши + и − также меняют размер.
При входе выбран логотип; выберите другой элемент на кадре или в списке слева.
Рамка и маркер размера активного элемента подсвечены, остальные приглушены.
Кнопка **«Поля 5%»** в редакторе показывает ориентир безопасной области и предупреждает,
если прямоугольник включённой штатной или дополнительной надписи касается полей или
выходит за кадр. Проверяются размеры текстовых блоков в текущем расположении, а не
реальная читаемость, светящиеся края или все фазы анимации; круговая надпись и
WebGL-элементы пока не проверяются. Поля 5% — ориентир, а не гарантия для конкретного
экрана. Ориентир и предупреждения не попадают в экспорт и отключаются той же кнопкой.
Кнопка с глазом справа от элемента скрывает или показывает его; скрытый элемент
можно снова включить в списке. Видимость сохраняется по сценам, входит в JSON и
видео и поддерживает отмену/повтор. Для круговой надписи и окружности это те же
переключатели, что в настройках; скрытие логотипа также прячет волны от его контура,
но не отключает другие эффекты сцены. Свойства выбранного элемента находятся в правой
панели: там можно выровнять элемент или сбросить позицию и размер по отдельности.
Раздел «Геометрия» позволяет ввести X, Y и масштаб или радиус численно: для
надписей смещение задано в процентах кадра (Y вниз), для объектов — в единицах
сцены (Y вверх). У привязанных объектов это смещение относительно опоры, а не
экранные координаты. Значения ограничены диапазонами редактора; ввод применяется
при подтверждении или уходе из поля, поддерживает отмену/повтор и недоступен при
блокировке геометрии.
На ширине окна от 781 пикселя панели расположены по сторонам кадра; на узком экране панели открываются кнопками «Слои» и «Свойства» поверх кадра. Список пока
показывает элементы готового шаблона и добавленные слои. Кнопка
«Добавить текст» создаёт до восьми дополнительных надписей на сцену; у каждой
можно изменить текст, цвет, положение и размер, скрыть её или удалить через
свойства. Кнопки «Выше» и «Ниже» меняют порядок только между своими надписями: в списке и таймлайне передние показаны выше, а новые и дублированные появляются поверх остальных. Порядок сохраняется в JSON и совпадает в редакторе и видео; старые настройки сохраняют прежний порядок слотов. Добавление, удаление и перестановка поддерживают отмену/повтор. Дополнительные
надписи по умолчанию используют шрифт сцены; в свойствах каждой можно выбрать
один из шести шрифтов или вернуть наследование. Выбор копируется, сохраняется в
JSON и поддерживает отмену/повтор. В тех же свойствах можно выбрать регистр:
как написано, прописные или строчные. Исходный текст не меняется, регистр
сохраняется и копируется вместе со слоем. Непрозрачность каждой собственной
надписи регулируется отдельно от её цвета и анимации; ноль не удаляет слой.
Она поддерживает отмену/повтор и копирование. Автоподгонка пересчитывается при смене
шрифта или регистра.
Штатные титры по умолчанию плавно проявляются без контура; в инспекторе для каждого можно выбрать также появление снизу или старую обрисовку. Сохранённые настройки круговой надписи не перезаписываются: в существующем проекте её можно выключить глазом в списке слоёв.

Добавленные надписи по умолчанию появляются и уходят вместе
с названием; в свойствах можно выбрать обрисовку (по умолчанию) или плавное
проявление готового текста без обводки, а также «Плавно снизу» — появление
с подъёмом и обратный уход вниз. Подъём составляет до 0,8% ширины кадра и
не меняет сохранённую позицию. Плавное проявление использует тот же
временной интервал, а его непрозрачность умножается на выбранную непрозрачность
слоя. Режим сохраняется и копируется вместе с надписью. Также можно выбрать «Своё время» и задать начало, конец и
плавность отдельно для каждой надписи. Начало и конец — проценты цикла после
стартовой задержки (показаны также секунды таймлайна); при изменении длительности
сцены они масштабируются вместе с ней; скорость воспроизведения влияет на реальное
время. Перемотайте нижним пультом внутрь интервала, чтобы увидеть надпись на
паузе. Плавность задаётся в процентах от самого интервала для каждого из переходов. Изменения поддерживают отмену/повтор, входят
в JSON и видео. Для каждой построительной окружности, каждого облака частиц и каждого
фонового свечения также можно выбрать в свойствах «Своё время» и задать
индивидуальный интервал и плавность. До и после интервала эффект не виден;
перемотайте воспроизведение внутрь интервала, чтобы расположить его на кадре.
По умолчанию эффекты сохраняют прежние фазы появления и ухода.
Кнопка «?» рядом с управлением просмотром открывает краткую справку по редактору и горячим клавишам. Escape закрывает справку, не закрывая редактор.

Над композицией находится управление просмотром: кнопка ▣ включает режим холста, временно скрывая боковые панели и таймлайн; повторное нажатие возвращает их. Режим сбрасывается при выходе из редактора и не меняет проект или экспорт. «−» и «+» меняют масштаб
относительно размера, вписанного в окно, а «Вписать» возвращает исходный вид.
При увеличении доступна «Рука»: перетаскивайте изображение или перемещайте его
стрелками клавиатуры (Shift — крупнее); Escape выключает инструмент и отменяет
незавершённое перетаскивание. Чтобы снова выбирать объекты мышью, выключите «Руку».
Масштаб и сдвиг относятся только к просмотру, сбрасываются при выходе из редактора
и не сохраняются в проекте. Окно предпросмотра обрезает увеличенный кадр.

На широком экране ширину панелей можно менять перетаскиванием разделителей.
Разделитель также доступен с клавиатуры: стрелки меняют ширину на 10 пикселей,
Shift — на 40, двойной щелчок возвращает стандартную ширину. При перетаскивании
Escape отменяет изменение. Ширины действуют до перезагрузки страницы и не входят
в настройки сцен или экспорт. Таймлайн занимает доступное пространство под кадром.
На узких экранах остаётся компактный режим с открытием панелей по кнопке.

Панель «Слои» позволяет искать элементы по имени и фильтровать текст или эффекты; фильтр влияет только на список, не скрывая элементы в кадре и на таймлайне. Счётчик показывает число найденных и доступных слоёв. На узком экране панели открываются кнопками «Слои» и «Свойства». Экспериментальный порядок эффектов находится в раскрываемом разделе панели слоёв.

Кнопки −1/+1 на таймлайне и Alt+стрелки при фокусе на линейке перемещают курсор по одному локальному кадру (на границах цикла останавливаются). При произвольном положении сначала выбирается ближайший кадр в направлении шага; перемотка ставит сцену на паузу.

Таймкод можно ввести вручную в формате `чч:мм:сс:кадры` и подтвердить Enter; Escape или потеря фокуса отменяют ввод. Значение за пределами цикла не принимается.

Таймлайн показывает локальный таймкод `чч:мм:сс:кадры` при 60 к/с. Он отсчитывается от начала цикла после задержки и не является номером кадра экспортного файла при изменённой скорости.

В редакторе пульт находится наверху: выбор композиции, воспроизведение, длительность и экспорт остаются доступными. Дублирующие перемотка и шаг по кадрам скрыты: для них используется таймлайн. На узких экранах верхнюю ленту можно прокручивать по горизонтали. После выхода обычный нижний пульт возвращается. В инспекторе раздел «Параметры объекта» содержит компактные раскрывающиеся группы настроек выбранного элемента; параметры, влияющие сразу на несколько элементов, помечены «общее». Общие настройки сцены и проекта остаются в отдельной панели ⚙.

Под кадром находится таймлайн элементов сцены. Для штатных названия, подзаголовка и даты (где они есть в сцене) в режиме «По сценарию» показана полоса «Маска титра»: границы ненулевой сценарной маски с учётом тактов интро и особого ухода финальной строки. При нахождении курсора внутри интервала полоса подсвечивается, если слой включён. Это не гарантия видимых пикселей: текст может быть пустым или заслонён. Нажмите на эту строку, чтобы включить собственный интервал и потянуть его границы; вернуться можно в инспекторе «Анимация → По сценарию». При первом включении границы приблизительно берутся из маски (с округлением до процента); заданные значения сохраняются при переключении режимов. Своё время управляет маской только выбранной строки: декоративные линии, шторка и движение финального титра остаются сценарными и могут перекрыть строку. У логотипа строка «По сценарию · задать своё время» включает отдельную прорисовку и проявление знака; стартовый собственный интервал — 25–90% цикла, а не реконструкция сценарных границ. Он влияет на контур, металлическое проявление и связанные с ним масштаб/уход в глубину. Камера, позиционное движение, точки черчения, вспышки, волны, надписи и чёрная шторка продолжают жить по сценарию, поэтому их связь со знаком может измениться, а шторка может скрыть знак. В инспекторе можно вернуться к «По сценарию», не теряя собственных значений. У неподдерживаемых штатных эффектов остаётся строка «Сценарий · без правки на шкале» без выдуманной полосы. Нажатие на название или строку выбирает элемент; скрытые элементы остаются в списке и отмечены. Добавленные тексты и эффекты, а также чертёжные линии имеют редактируемые интервалы. Над дорожками показаны базовые фазы сцены: метки меняют длительность прорисовки/проявления и ухода/паузы пропорционально, за счёт удержания, не изменяя общий цикл. Мышь и стрелки позволяют перемещать метки; Shift ускоряет шаг, Escape отменяет жест, изменения можно отменить. При увеличении длительности в пульте меняется только удержание. Дополнительные такты интро (появление боковых кругов, подъём и титры) пока частично проходят внутри удержания и настраиваются отдельно; собственные интервалы элементов по-прежнему заданы в процентах от всего цикла. Строка «По сценарию»
не показывает точный интервал: нажмите её, чтобы включить «Своё время». После этого
полосу можно перетаскивать за середину целиком без изменения её длины, а края — отдельно. Выберите полосу или край и перемещайте также стрелками клавиатуры;
Shift ускоряет шаг, Escape отменяет текущий жест. Один жест — один шаг истории.
В инспекторе «Анимация» кнопки «Начало = курсор» и «Конец = курсор» ставят границу на ближайший кадр относительно текущего курсора, если сохраняется минимальная длина интервала. Поля «Начало, с» и «Конец, с» принимают секунды после стартовой задержки (до 0,001 с); подтвердите Enter. Границы не могут пересекаться, минимальный интервал — 1% цикла. В конфиге сохраняются проценты, поэтому при изменении длительности цикла секунды пересчитываются. Перетаскивание краёв на шкале округляет их до целых процентов.
Нажатие или перетаскивание по верхней линейке перематывает и ставит воспроизведение
на паузу; линейка показывает секунды цикла после стартовой задержки. Штатные боковые эффекты пока нельзя напрямую настраивать по времени через эти строки. Таймлайн не
попадает в видео. Ключевые кадры, загрузка изображений и произвольный порядок
всех элементов, включая WebGL-эффекты и штатные титры, ещё не реализованы.
В инспекторе разделы «Оформление», «Геометрия», «Анимация» и «Порядок» можно сворачивать; доступные разделы зависят от выбранного элемента. Их состояние действует только до перезагрузки страницы и не меняет настройки сцены. У координат показаны проценты кадра для текста или единицы сцены для пространственных элементов; масштаб — множитель, радиус — единицы сцены.

В свойствах надписи можно сразу изменить её текст и цвет, а также вернуть исходные
текст или оформление. Цвет круговой надписи фотопаузы теперь независим от
уголков; прежние JSON без отдельного цвета сохраняют общий цвет. В свойствах знака
меняется общий цвет золота сцены (он влияет и на связанные эффекты), у
окружности — цвет декора. Тексты и цвета сохраняются по сценам в настройках и
JSON и используются в видео. Для каждой строки обычных титров доступно до 120
символов, для круговой надписи — до 40. При
перетаскивании края и центры притягиваются к кадру и другим элементам;
пунктирные направляющие показывают совпадения. Зажмите Alt для свободного
перемещения без прилипания. Стрелки перемещают выбранный элемент, Shift ускоряет шаг.
Когда выделенная строка слоя или его рамка находится в фокусе, Ctrl/Cmd+D
дублирует добавленный элемент, а Delete или Backspace удаляет его. Эти команды
работают для своих надписей, окружностей, облаков и свечений; штатные элементы
удалить или дублировать так нельзя. В полях ввода и на таймлайне они не
перехватываются. Обе операции поддерживают отмену/повтор; при занятом лимите
копирование ничего не меняет.
Кнопки «Отменить» и «Повторить» (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z или Ctrl+Y)
возвращают перемещение, размер, выравнивание, видимость, текст, цвет и сброс на кадре. Один жест —
один шаг; до 100 шагов хранятся отдельно для каждой сцены до перезагрузки.
Правки других настроек панели не входят в историю; при изменении в панели
параметра, который уже есть в истории, или при импорте/сбросе сцены история
этой сцены очищается, чтобы не затереть новое значение. Escape во время
перетаскивания отменяет текущий жест.
В списке элементов кнопка с замком блокирует перемещение и изменение размера
в редакторе: мышью, клавишами, выравниванием и сбросом геометрии. Блокировка
сохраняется отдельно в каждой сцене и поддерживает отмену/повтор; добавленный
или дублированный элемент начинает разблокированным. Она не запрещает правку
текста, видимости и времени, изменение через общие настройки или движение
привязанного элемента вместе с родителем; на экспорт блокировка не влияет.

В свойствах добавленных надписей, построительных окружностей, облаков и свечений
можно задать **имя слоя** (до 48 символов). Оно видно в списке и на таймлайне,
хранится отдельно в каждой сцене и не меняет текст в кадре. Пустое имя возвращает
стандартное название. Переименование поддерживает отмену/повтор и копируется
вместе со слоем. Штатные элементы пока не переименовываются.

Для этих элементов также есть кнопка «Дублировать». Копия занимает свободный слот того же типа, наследует
настройки, видимость и время, и слегка сдвигается, чтобы её было удобнее выбрать.
Дальнейшие изменения копии не затрагивают оригинал; дублирование отменяется одним
шагом. Если все слоты этого типа заняты, кнопка недоступна. Встроенные логотип,
титры и фоновые круги пока не дублируются.
В интро и финале на раннем этапе включено крупное центральное перекрестие с угловыми перекрестиями; окружность сохраняется. В остальных сценах через список элементов доступны чертёжные направляющие; в сцене 02 они по умолчанию выключены. Их можно отключить глазом, переместить, изменить размер, цвет и время; перекрестия привязаны к центрам двух существующих боковых кругов и не смещаются вместе с центральной разметкой.
«Готово» закрывает редактор; воспроизведение можно продолжить из пульта.
Изменения сохраняются отдельно для каждой сцены и входят в JSON и экспорт.
В фирменном фоне и фотопаузе круговую надпись можно сдвинуть за круглую ручку на её верхнем
крае; соседний квадратик меняет радиус. Размер букв круговой надписи задаётся
отдельно в настройках, а её положение отсчитывается от логотипа.
В любую сцену можно добавить до четырёх построительных окружностей кнопкой под
списком элементов. Каждую можно переместить за круглую ручку, масштабировать,
настроить, скрыть или удалить. Привязка к логотипу включается отдельно для
каждой окружности и переключается без скачка положения. В сцене 02 первая
окружность уже добавлена и привязана к знаку; другие сцены по умолчанию не
изменяются. Прозрачность линий и яркость орбитальной пыли по отдельности
регулируются в свойствах окружности. Удаление освобождает слот для новой окружности.
Кнопка «Добавить облако частиц» создаёт до четырёх независимых облаков на сцену.
Каждое можно перемещать, масштабировать, скрывать и удалять отдельно от знака,
фоновых кругов и других облаков. Цвет и яркость задаются в свойствах, количество,
размер частиц и скорость вращения — в «Настройках элемента». У каждого нового облака
свой воспроизводимый рисунок частиц; при дублировании рисунок копируется. Удалённое
облако освобождает слот для нового.
По умолчанию облака появляются и уходят вместе с фазами сцены, а существующие
фоновые частицы настраиваются отдельно.
Кнопка «Добавить свечение» создаёт до четырёх фоновых ореолов на сцену. Каждый
выбирается отдельно в списке: его положение, радиус, цвет и видимость независимы
от других ореолов, логотипа и боковых кругов; яркость задаётся в свойствах, а
пульсация — в настройках выбранного элемента. При удалении освободившийся слот можно занять
новым свечением. По умолчанию ореолы появляются и уходят по фазам сцены. Это визуальное
свечение на фоне, а не источник освещения металла. Изменение интенсивности
поддерживает отмену/повтор и сохраняется при копировании и в JSON; оно не
управляет порядком эффектов.

В списке можно включить экспериментальный **«Порядок эффектов»** и для каждой
добавленной окружности, облака или свечения использовать «Выше» и «Ниже».
Выше в списке — рисуется позже. По умолчанию режим выключен, поэтому старые
сцены сохраняют прежнюю сортировку. Включение переводит добавленные эффекты
после штатных прозрачных объектов (кроме финальной чёрной шторки), поэтому
их смешивание со штатными элементами может измениться. Непрозрачные объекты
по-прежнему перекрывают эффекты согласно глубине; аддитивные эффекты не всегда
визуально меняются при перестановке. Режим не меняет порядок надписей и не
является свободной сортировкой всех элементов. Настройка, операции перестановки,
добавления и дублирования поддерживают историю и сохраняются отдельно по сценам.
Штатный «Верхний свет и ореол» доступен во всех сценах в списке элементов:
круглая ручка рядом с центром ореола перемещает его вместе с источником света,
который освещает металл. Размер и цвет ореола, цвет источника и видимость можно
менять отдельно от логотипа; яркость обоих задаётся в настройках «Свет и тени».
Ореол масштабируется, но радиус действия источника света не меняется. Перемещение,
размер, цвет и видимость поддерживают отмену/повтор и сохраняются в JSON. По
умолчанию сохраняются исходные положение, цвета и фазы сцены; отдельных копий и
собственного тайминга у штатного света пока нет.
Левый и правый фоновые
круги теперь выбираются в списке или за круглые ручки в их центрах; у каждого
отдельно можно переместить центр, изменить масштаб и цвет свечения или скрыть
его вместе с привязанными орбитальными частицами, боке и светом на фоне.
Основной цвет линий и прочие параметры пока общие и доступны через «Настройки
элемента». Если общий эффект колец выключен в настройках, кнопка видимости
включает его обратно (и восстанавливает ранее включённые стороны). Декоративные
линии, общий фон и некоторые существующие эффекты пока не являются отдельными перемещаемыми
слоями; произвольное добавление других типов объектов ещё не реализовано. Рамки редактора не попадают в видео. Быстрая проверка интерфейса без WebGL:
`URL=http://localhost:5173 npm run verify:editor:lite`.

## Дальнейшая серия
Виды №1, 2, 8 и 9 готовы. В дальнейшем на общей визуальной основе планируются №3 «Проект мечты», №4 «Партнёры вечера», №5 «Янтарный циркуль: помним всё», №6 «ТЗ с подвохом», №7 «Проектировщик объясняет». Их сценарии и тексты уточняются отдельно.


### Проверка воспроизводимости кадров

После запуска dev-сервера `URL=http://localhost:5175 npm run verify:frame-determinism` сравнивает фактические WebGL + canvas-композиты трёх моментов каждой готовой сцены при двух разных порядках перемотки. По умолчанию WebGL считается в 320×180 ради скорости, а композит собирается в 1920×1080. С `MODIFIED=1` проверяются изменённые тайминги, собственная надпись, облако, свечение и порядок эффектов. Для отдельной сцены и полноценного разрешения можно задать `SCENES=waiting RENDER_WIDTH=1920`; такой прогон значительно медленнее. Проверка не охватывает все моменты и настройки, переходы или сам MP4-кодер и не является художественной оценкой.

### Замер рендера

`URL=http://localhost:5175 npm run benchmark:render` измеряет прогретый рендер реальной сцены и сборку экспортного canvas для размеров WebGL 320×180, 960×540 и 1920×1080. Можно выбрать `SCENE=finale`, `WIDTHS=320,1920` и `SAMPLES=3`. Скрипт сообщает браузерный WebGL renderer и отдельные времена; в software WebGL прогон может быть долгим. Это не измерение кодирования MP4 или FPS на другом компьютере.

Проверка собственного времени штатного титра на реальной сцене: `URL=http://localhost:5175 npm run verify:caption:timing`; доступны `SCENE=finale CAPTION=subtitle` и другие штатные строки. Проверяются DOM-маска и экспортный canvas до, внутри и после интервала, не кодирование MP4.

Проверка собственного времени логотипа: `URL=http://localhost:5175 npm run verify:logo:timing`, с `SCENE=brand`, `photo-pause` или `finale` — для других сцен. Проверяется вклад геометрии знака в экспортный canvas, но не связанные эффекты и не готовый MP4.

`URL=http://localhost:5175 npm run verify:custom-timing:video` записывает короткий MP4 интро с собственными интервалами знака и заголовка, проверяет число кадров и сравнивает три декодированных кадра с исходным canvas с допуском на сжатие. Тест отдельно проверяет вклад знака в средний кадр. Используются искусственно сокращённый цикл и скорость; это не просмотр полного ролика и не проверка остальных сцен.

Для добавленных окружностей, облаков частиц и свечений при включённом «Своё время» доступен «Характер проявления»: обычный, мягкий или яркий. Это варианты огибающей прозрачности/интенсивности, а не новые физические эффекты; границы интервала и остальные движения не меняются. Выбор сохраняется в JSON и поддерживает отмену. По умолчанию и в сценарном режиме прежний вид сохраняется.

Отдельный **прототип архива** открывается по ссылке «Архив ↗» в пульте или на `archive.html`. Десять составных медиаграней по сторонам траектории принимают локальные фото и видео; камера направлена вперёд, полигонального тоннеля нет. Для каждого доступно кадрирование «Заполнить» / «Вписать»; в режиме «Заполнить» кнопка ↔ позволяет сместить область кадрирования по X и Y; изображение ограничено формой грани и её края могут срезаться; у видео можно указать диапазон или кнопкой ↦ подставить метку исходника. Это работа предпросмотра, не сохранение обрезанного файла. Видео без звука, файлы и настройки не сохраняются после перезагрузки. Превью имеет пропорции 16:9; эпизоды пока по 8 секунд. Это не готовая заставка: покадровый экспорт MP4 и включение в цепочку не реализованы. Подробности — в `docs/archive-composition-plan.md`; `URL=http://localhost:5175 npm run verify:archive` проверяет синтетические файлы и интерфейс, но не экспорт.
